# Design context

- Audience: the project owner, operating a physical EmotionBot head beside the browser while calibrating its servos.
- Jobs: select one servo, a pair, or a custom group; observe a bounded 90-degree test; slowly explore angles and direction; save positions and physical observations; release immediately.
- Tone: dark instrument panel, explicitly chosen by the user on 2026-11-13. Clear readings, accessible large controls, restrained amber accents, persistent release control.
- Constraint: displayed angles are controller state, not encoder feedback. Real and simulated modes must remain visibly distinct; loading a page must never move hardware.
