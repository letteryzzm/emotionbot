# 颈部支架

原版没有底座。`heightmap.py` 量头骨框架后下方的底面 → `make_stand.py`（Blender 无界面运行）生成底板 + 两根斜立柱，立柱顶面按框架底面横梁拟合（间隙 0.5 到 8 mm，平均 1.5 mm），每根立柱 y≈80 处有扎带孔。

- 下巴绕 MG996R 轴转，张嘴 45° 时最低 z=-131、最靠后 y=40.9；立柱从 y=50 开始，底板顶面 z=-142（张到 45° 还有 10.6 mm 余量）
- 整头约 870 g，重心 y≈-9（脸在 y 负方向）；底板伸到 y=-105
- 已检查：静止零件、下巴 0 到 45° 全行程和支架都没有干涉
- 输出：`outputs/neck_stand/NeckStand_颈部支架_x1.stl`（打印坐标，底面 z=0）、`stand_asm.npz`（装配坐标）

## v2 转锁支架（2026-11-06）

v1 卡不住头：立柱只顶在头骨后部，重心比支撑靠前约 59 mm，全靠扎带拉住，也没有任何限位。v1 文件保留，不再使用。

头骨底板其实有接口：厚 6.3 mm，倾斜 8°，六边形孔对边 50 mm，周围 4 个盲槽 8.0 × 19.6 × 2 mm。v2 用它做转 30° 锁定：

- 后方 ±30° 两处唇边压住底板上表面，间隙 0.3 mm，头最多前倾约 0.5°
- 前方一个凸键进盲槽防转。重心靠前，头总是前沿下压，所以键放前面；后方的键会脱开
- 法兰半径 30（底板下有竖筋，`|u|` 30.5 到 34.5，会随头转动）
- 只能从 `+30°` 这一侧转入，另一侧被键座挡住
- 脖子空心，后方开槽走线

`make_stand_v2.py` 用 manifold3d 生成（Blender 的 EXACT 布尔在这个模型上不可靠）。`verify_v2.py` 在 Blender 里做三角形级干涉检查，结果在 `outputs/neck_stand/v2_干涉检查.txt`。下巴按刚体绕 (y=-2, z=-41) 旋转近似。

## 旧底座转接环（2026-11-06）

`make_adapter_v1.py` 在 v1 立柱顶上加 v2 的转锁接口，不用重打底座。头比 v2 抬高 20 mm，这样竖筋转动时不会撞 v1 立柱。底面是 v1 立柱的负形，单边留 0.25 mm；转接环靠 2 根扎带穿 v1 扎带孔固定，每根受力约 10 N 以内。

干涉检查结果在 `outputs/neck_stand/v1转接_干涉检查.txt`（`STAND_NPZ=outputs/neck_stand/adapter_v1_asm.npz` 运行 `verify_v2.py`）。

## 方案对比（2026-11-06）

头骨孔的 ±30°、±150° 四条边上沿有局部 45° 倒角（`r = w + 20.67`），±90° 两边没有。`make_stand_v2.py`、`make_adapter_v1.py` 没考虑这个，唇边实际间隙约 2.3 mm，已作废。以 `make_variants.py` 为准。

唇边斜面贴合倒角，法兰后半圈降低 1.6 mm，转动时把脸抬 2.4° 让底板后部下沉。去掉前键时，放在锁定位也只能转约 ±1°，所以倒角本身就防转。

| 方案 | 上提极限 | 前倾极限 | 用到的结构 | 额外零件 | 结论 |
|---|---|---|---|---|---|
| A 一键转锁 | 0.30 mm | 0.2° | 孔、后方倒角、1 盲槽 | 无 | 推荐 |
| B 三键转锁 | 2.40 mm | 1.7° | 孔、3 盲槽 | 无 | 不推荐，后键静止时脱开 |
| C 顶丝转锁 | 0.30 mm，拧紧后 0 | 0.2°，拧紧后 0 | A + 后方 2 盲槽 | 2 × M3 | A 不够时用 |
| D 弹性键 | 0.30 mm | 0.2° | 孔、倒角、3 盲槽 | 无 | 不推荐，悬臂应变约 1.8% |
| E 直落压板 | 0.15 mm，拧紧后 0 | 拧紧后 0 | 孔、4 倒角、4 盲槽 | 压板 + M4 | 最牢，装配最麻烦 |

检查项：落座、下巴 0 到 45°、插入和转动路径。C、E 拧紧后的 0 是推算，模型里没有模拟螺丝预紧。

## 最终：一体底座（2026-11-06）

用户决定整座打印，不用转接环。`make_stand_final.py` 把方案 A 的接口直接做在底座上，头不抬高。检查结果在 `outputs/neck_stand/一体底座_干涉检查.txt`：上提极限 0.30 mm，前倾极限 0.2°，其余姿态无干涉。
