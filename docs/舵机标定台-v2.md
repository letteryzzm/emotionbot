# 舵机标定台 v2：90° 检查、慢速探索与位置记录

2026-11-13。用户选择深色仪器风格，按实际调试顺序重新组织页面。入口仍是 `http://127.0.0.1:8770/`，由 `scripts/tune_server.py` 独占串口；无 T5，无第二个控制进程。

## 操作

1. **选电机。** 左侧支持单个、成对、自选组，也可直接选一个功能组。JL/JR 共用下巴机构，必须成对；EXA 不参与。切换对象前先全部卸力。含隔离通道的组合不能通电。
2. **直接通电手动调节。** 点击“通电并手动调节”，立即开放滑块和微调按钮。使用控制器当前记录的角度作为起点，不强制先去 90°，不套用保存的中心补偿。当前控制角度不等于实际轴角测量，卸力后被外力移动的机构通电时仍可能转动。
3. **慢速调整。** 默认 5°/秒，可选 10 / 20 / 30°/秒；支持滑块和 ±0.5° / ±1°。按方向联动可让所选组同时调整，也可关闭后逐个调；下巴始终成对反向。填写方向说明便于复现。切换方向与观察选项不构成通电或移动命令。
4. **观察与 90° 检查都是独立功能。** “达到预期姿态”、声音、抖动和发热只作为记录，选“否”或“未确认”也不限制手动调节。需要单独检查 90° 时展开可选检查，设置 5 / 15 / 30 秒；倒计时内可点“转为手动调节”，无需先填写观察，也不自动生成合格记录。
5. **记录位置。** 填写名称，保存当前所选组合的原始角度、方向、观察和时间。普通位置、上下边界候选与问题样本均可记录；候选不会自动覆盖正式限位。运行中需等软件读回接近最新目标。卸力后仍可补记本页面刚结束会话的最后已知控制状态，记录中明确标为 `last_controller_state`，不假称卸力后的位置测量。
6. **返回与导出。** 相同组合在范围探索中可慢速返回记录位置。配置或中心改变后，旧位置不能直接重放。导出 JSON 留作备份。七类表情另存于下方折叠的表情库：先 neutral，其他标签通道必须一致。

Esc / 顶部“全部卸力”随时中断。连接租约为 5 秒；页面关闭会尝试立即卸力，失联则由服务端超时卸力。90° 检查的总时长不会被心跳延长；手动会话最长 15 分钟。刷新页面不会恢复通电，也不会接管另一个页面的会话。

这些保护依赖上位机仍在运行且串口能够发送命令；服务崩溃、USB 断开等情况不保证能卸力。Pico 目前没有为本流程增加独立的硬件安全回路；发现仍受力时断开舵机电源。

## 数据与实现

| 内容 | 路径 / 规则 |
|---|---|
| 页面 | `head/web/calibration.html`、`.css`、`.js` |
| 标定控制 | `head/calibration_session.py`，复用 Bench 串口锁、连接和故障隔离 |
| 位置与观察 | 表情库旁的 `<表情库文件名去扩展名>-positions.json`，默认 `calibration/expressions-positions.json` |
| 七类表情 | `calibration/expressions.json`，保持现有版本和 neutral 基准检查 |
| 过程与 LLR 备注 | `outputs/tune_log.jsonl` |
| 仿真 | `--sim`，默认 `outputs/calibration-sim/`，与真机模式互斥 |

位置文件使用原子替换、文件锁与磁盘版本检查，防止写到一半或旧进程覆盖新数据。每条记录含配置指纹。原始角度不再加一次中心偏移。所有记录默认只是命令状态与人工观察；没有电流、温度或位置传感器自动验收。

前端最多保留一个待发送的最新滑块目标；服务端使用递增序号拒绝迟到指令。每 100 ms 最多推进 3°，按统一比例插值保留下巴耦合约束。串口耗时可能使实际指令推进更慢；5°/秒是上位机离散目标的推进速度，不是实测轴速度。默认配置范围与已记录正式范围取交集。通电请求携带控制状态版本，已被卸力操作取消的旧请求不会重新通电。

## API

均为 `POST /api`，带 `X-Head: 1`；返回状态在 `state.calibration`。接口错误返回 400，不能当成功处理。

| 操作 | 参数与作用 |
|---|---|
| `cal_begin` | `names`、可选 `epoch`；`manual: true` 从当前指令角度直接进入手动模式，默认 false 保留限时 90° 检查（`duration` 1–30 秒） |
| `cal_touch` | `token`；续连接租约，不延长总观察时长 |
| `cal_range` | `token`；把限时 90° 检查转为手动模式；可选 `observation` 仅供记录，不作为许可条件 |
| `cal_target` | `token`、递增 `seq`、完整 `angles`、`speed` 5–30；替换最新目标 |
| `cal_capture` | `token`、`name`、`kind`、`observation`、可选 `directions`；记录当前或刚结束的会话 |
| `cal_restore` | `token`、`record_id`、`seq`、`speed`；检查组合、配置与限位后设置目标 |
| `cal_stop` | `token`；仅停止对应会话，旧页面不能停止后来新建的会话 |
| `relax` | 全部卸力，仍为通用紧急操作 |
| `GET /positions.json` | 导出全部位置记录；状态接口仅附最近 100 条 |

`observation` 包含 `reached`、`buzz`、`jitter`、`heat`，值为 `yes` / `no` / `unknown`，另有 `text` 字符串。`kind` 为 `center` / `position` / `lower` / `upper`。上述接口都不推断人体情绪，仍会拒绝当前明确禁用的通道。
