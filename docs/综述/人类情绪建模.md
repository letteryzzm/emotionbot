# 人类情绪建模：五大流派与核心模型

> 起因：读 Stock-Homburg 2022 综述 时，综述把 FACS、环形模型、Plutchik 情绪轮并列成"人类情感的经典概念"（4.1 节表格第 1 类），但它们其实不在同一个层次上。这篇笔记先用心理学的五大流派搭一张总地图，再逐个讲清楚每个模型怎么建模、各自优劣、彼此是什么关系。
> 相关：Breazeal 2003 精读 第 4 节（基本情绪论 vs 成分论）、第 6 节（情感评价）、第 7 节（Affect Space）。

## 0 一句话结论

- 心理学对情绪的建模可以分成**五大流派**：离散论、维度论、评价论、建构论、经典生理理论。它们**回答的不是同一个问题**：
  - ① 离散论和 ② 维度论回答"**情绪有什么结构**"：是几种类别，还是连续空间里的点；
  - ③ 评价论回答"**情绪为什么产生**"：同一件事，评价不同，情绪就不同；
  - ④ 建构论回答"**类别是不是真实存在**"：它认为类别是大脑临时建构出来的，因此质疑 ①；
  - ⑤ 经典生理理论回答"**身体反应和情绪体验谁先谁后**"，是前面几派的历史源头。
- **FACS 不属于任何一派**。它是测量工具，只记录"脸上的肌肉怎么动"，本身不说是什么情绪。综述里"FACS 包括六种基本情绪"这句话**不准确**：六种基本情绪来自 Ekman 的**基本情绪理论**。HRI 论文里说的"FACS emotions"，意思是"用 FACS 原型表达出来的基本情绪"。
- 落到机器人上：**类别**方便设计和评估，**维度**方便连续生成和插值，**评价论**决定机器人"自己的"情绪从哪来，**FACS** 是把脸和执行器对接的中间表示。真实系统通常几种一起用，Kismet 就是"评价论 + 维度表示 + 类别仲裁"的组合。

## 1 先定义几个词

| 词 | 含义 |
|---|---|
| **类别论 / 离散论（categorical / discrete）** | 认为情绪是有限个离散的种类，比如快乐、愤怒，每种有自己的表情和生理模式 |
| **维度论（dimensional）** | 认为情绪是连续空间里的一个点，用几个坐标轴描述，类别只是空间里的模糊区域 |
| **效价（valence）** | 情绪的正负，也就是愉快还是不愉快 |
| **唤醒度（arousal）** | 情绪的激活程度，从困倦、平静到兴奋、紧张 |
| **评价（appraisal）** | 人对一件事的主观评估，比如"这和我有关吗""我能应对吗" |
| **核心情感（core affect）** | 建构论的用语：任何时刻都存在的、由 valence × arousal 描述的底层感受状态 |
| **AU（Action Unit，动作单元）** | FACS 的基本单位，对应一块或一组面部肌肉的一种可见动作 |
| **原型（prototype）** | 某种情绪最典型的 AU 组合，比如"真笑"= AU6 + AU12 |

## 2 流派总览

### 2.1 五大流派

| 流派                                      | 回答的问题      | 核心观点                             | 代表模型                                                      | 对机器人头项目的用处                      |
| --------------------------------------- | ---------- | -------------------------------- | --------------------------------------------------------- | ------------------------------- |
| ① 离散 / 基本情绪论（discrete / basic emotions） | 情绪有哪几种？    | 情绪是少数由进化形成、彼此独立的类别               | Ekman 6 类、Izard DET、Plutchik 情绪轮、Panksepp 7 系统            | 数据集标签（7 类）、识别率评估                |
| ② 维度论dimensional                        | 情绪在什么空间里？  | 情绪是连续空间里的点，各模型的差别只在于用几个轴、哪几个轴    | Wundt、Russell 环形、PAD、PANAS、Thayer、Fontaine 四维、Lövheim 立方体 | V/A 输出、表情插值生成                   |
| ③ 评价论（appraisal）                        | 情绪为什么产生？   | 情绪来自对事件的评估，不是事件本身直接引起的           | Lazarus、Scherer CPM、OCC、Frijda、Smith & Ellsworth、Roseman  | 生成端：机器人"自己的"情绪从哪来               |
| ④ 建构论（constructionist）                  | 类别是真实存在的吗？ | 情绪不是天生的固定类别，而是大脑结合核心情感和语境临时建构出来的 | Russell 核心情感、Barrett 情绪建构论                                | 提醒：从人脸"读出情绪类别"这件事本身有争议          |
| ⑤ 生理 / 经典理论                             | 身体和体验谁先谁后？ | 19 世纪末到 20 世纪中期关于身体反应和情绪体验关系的争论  | James–Lange、Cannon–Bard、Schachter–Singer、Damasio          | 历史背景；Damasio 的躯体标记被 Kismet 直接借用 |

### 2.2 它们怎么串起来

```
 ⑤ 经典生理理论（1884–1962）：身体反应和情绪体验，谁先谁后？
        │
        │  Schachter–Singer："生理唤醒 + 认知标签 = 情绪"
        │  → 认知解释这一半发展成 ③，唤醒这一半发展成 ② 的 arousal 轴
        ▼
 ③ 评价论：  事件 ──(评价：相关吗？好坏？能应对吗？)──► 情绪
                                                     │
                                       这个情绪用什么来表示？
                                       ┌─────────────┴─────────────┐
                                       ▼                           ▼
                             ① 离散论：类别标签            ② 维度论：坐标点
                             Ekman / Izard / Panksepp      Russell / PAD / Fontaine
                                       ▲                           │
                                       │   ④ 建构论：               │
                                       └── 类别 = 核心情感(②) ─────┘
                                           + 概念 + 语境
                                           （质疑 ① 的"天生固定"）

 ─────────────────────────── 测量层 ───────────────────────────
 FACS：把 ① 的类别（EMFACS 原型）或 ② 的坐标（回归）落到脸上 → 机器人执行器
```

图的读法：

- **纵向是因果链**：⑤ 提出"身体和认知"两个成分；③ 讲事件怎样经过评价变成情绪；①② 讲这个情绪用什么表示。
- **① 和 ② 是同一个问题的两种答案**，可以互相转换：类别可以看成维度空间里的区域，维度坐标也可以聚类成类别。
- **④ 是对 ① 的批评**：它承认 ② 的核心情感是底层，但认为 ① 的类别不是天生的，是大脑结合概念和语境建构出来的。
- **FACS 在最下面的测量层**，和上面任何一派都不冲突。

### 2.3 两个容易混的归类

- **Plutchik 放在 ① 还是"介于类别和维度之间"**：看角度。按核心假设，他认为情绪是进化来的基本类别，属于 ①；按表示形式，他加了强度和对立结构，有维度的味道。第 6 节单独讲。
- **Russell 同时出现在 ② 和 ④**：不矛盾。环形模型（1980）是一种**表示方法**，属于维度论；核心情感理论（2003）是他后来对"类别从哪来"的**解释**，属于建构论。

## 3 FACS：给脸上的动作编码（测量工具，不属于任何流派）

**出处**：Ekman & Friesen 1978 的编码手册；2002 年 Ekman、Friesen、Hager 出了修订版，现在用的是这一版。

### 3.1 怎么建模

把一张脸拆成若干 **AU** 的组合，每个 AU 再标一个强度等级 A（最弱）到 E（最强）。

```
一张脸 = { AU_i : 强度 }，例如 { AU6: C, AU12: D }
```

常用 AU（下一节的原型会用到）：

| AU | 名称 | 动作 |
|---|---|---|
| 1 | Inner brow raiser | 眉头内侧上抬 |
| 2 | Outer brow raiser | 眉毛外侧上抬 |
| 4 | Brow lowerer | 皱眉、眉毛下压 |
| 5 | Upper lid raiser | 上眼睑上抬（瞪眼） |
| 6 | Cheek raiser | 脸颊上提（眼角出鱼尾纹） |
| 7 | Lid tightener | 眼睑收紧 |
| 9 | Nose wrinkler | 皱鼻 |
| 12 | Lip corner puller | 嘴角上拉 |
| 14 | Dimpler | 嘴角内收出酒窝 |
| 15 | Lip corner depressor | 嘴角下拉 |
| 16 | Lower lip depressor | 下唇下拉 |
| 20 | Lip stretcher | 嘴角横向拉开 |
| 23 | Lip tightener | 嘴唇收紧 |
| 26 | Jaw drop | 下巴下落、张嘴 |

### 3.2 FACS 怎么连到情绪：EMFACS 原型

FACS 本身不含情绪。把 AU 组合对应到情绪的，是 **EMFACS**（Emotion FACS）这类原型表：

| 情绪 | 典型 AU 组合 |
|---|---|
| 快乐 happiness | 6 + 12 |
| 悲伤 sadness | 1 + 4 + 15 |
| 惊讶 surprise | 1 + 2 + 5B + 26 |
| 恐惧 fear | 1 + 2 + 4 + 5 + 7 + 20 + 26 |
| 愤怒 anger | 4 + 5 + 7 + 23 |
| 厌恶 disgust | 9 + 15 + 16 |
| 轻蔑 contempt | 单侧 12A + 单侧 14A |

注意这是"最典型"的组合，真实表情经常只出现其中一部分，或者混进别的 AU。第 8 节的建构论正是抓住这一点质疑基本情绪论。

### 3.3 优劣

| 优点 | 缺点 |
|---|---|
| 客观，按解剖结构定义，不同编码者之间一致性高 | 只管**脸**，不管身体、声音 |
| **不绑定任何情绪理论**：同一组 AU 可以映射到类别，也可以回归到 V-A | 描述的是**外观**，不等于内部状态：假笑也有 AU12 |
| 能编码混合表情和强度 | AU 和情绪是**多对多**关系，要靠语境判断 |
| 和执行器天然对应：android 脸（如 Hara 的硅胶脸）就是按 AU 布置控制点 | **机械脸自由度少，很多 AU 做不出来**（比如没有脸颊就没有 AU6） |
| | 人工编码非常费时，需要专门培训认证 |

### 3.4 一个推断：为什么恐惧最难认

综述 Table 2 里，人对机器人恐惧表情的识别率最低（43.8%）。对照 3.2 节的原型表：恐惧和惊讶共用 AU1 + 2 + 5 + 26，区别主要在 AU4（皱眉）和 AU20（嘴角横拉）。很多机器人脸做不出这两个动作，恐惧就容易被认成惊讶。

> 这一条是我结合原型表推出来的，综述本身没有这样分析。Breazeal 那篇里 Kismet 的 fear 也是识别率最低的。

## 4 ① 离散 / 基本情绪论：情绪是离散的类别

**核心观点**：情绪是少数几种由进化形成、彼此独立的类别，每种有自己的触发条件、生理模式和表情。

### 4.1 Ekman 基本情绪

**出处**：Ekman 1971 年起的跨文化研究；理论总结见 Ekman 1992，*An argument for basic emotions*。

- 情绪分为少数几种**基本情绪**：快乐、悲伤、恐惧、愤怒、惊讶、厌恶，后来加上轻蔑（contempt）。
- 每种基本情绪被认为有：跨文化通用的面部信号、独特的生理模式、快速自动的触发方式。
- 其他情绪（比如兴趣、好奇、羞愧）看作**次级情绪**，或者基本情绪的组合。
- 表示方法：一个 one-hot 类别标签，最多再加一个强度。

### 4.2 其他离散模型

| 模型 | 内容 | 和 Ekman 的区别 |
|---|---|---|
| **Izard 差别情绪理论（DET）** | 约 10 种基本情绪：兴趣、喜悦、惊讶、悲伤、愤怒、厌恶、轻蔑、恐惧、羞愧、内疚 | 多了**兴趣**和**羞愧、内疚**这类社会性情绪；强调情绪是独立的动机系统 |
| **Plutchik 情绪轮** | 8 种基本情绪，两两相对，带强度和混合规则 | 结构最丰富，第 6 节单独讲 |
| **Panksepp 情感神经科学** | 7 个皮层下原始情绪系统：SEEKING、RAGE、FEAR、LUST、CARE、PANIC/GRIEF、PLAY（习惯用大写，表示指的是神经回路，不是日常词义） | 不从表情出发，而是从**动物脑的神经回路**出发；SEEKING 和多巴胺系统相关，可以和 RL 里的奖励、探索联系起来 |

### 4.3 优劣

| 优点 | 缺点 |
|---|---|
| 标签离散，最容易**设计**（每类做一个表情）和**评估**（让被试从几个选项里选） | 类别太少，机器人表情容易**重复**，这就是综述批评静态生成方法的原因 |
| 有跨文化证据，标签含义大家都懂 | 表达不了强度变化、混合情绪、情绪之间的过渡 |
| 现成数据集多（AffectNet、RAF-DB、M3ED 都用这套标签） | 强制选择的评估方式会抬高识别率：只有 6 个选项时，瞎猜也有约 17% |
| | 不同学者列出的"基本情绪"数量和种类都不一样（6、7、8、10 种），本身说明"哪些算基本"没有定论 |
| | "普遍性"受到建构论的挑战，见第 8 节 |

## 5 ② 维度论：情绪是连续空间里的一个点

**核心观点**：情绪是连续空间里的一个点。不同的维度模型，区别只在于用几个轴、每个轴代表什么。

### 5.1 Russell 环形模型

**出处**：Russell 1980，*A circumplex model of affect*（文件在 `09_情感计算/Russell_1980_...`）。

- 两个连续、两极的维度：
  - 横轴 **valence**：不愉快 ↔ 愉快
  - 纵轴 **arousal**：平静 ↔ 兴奋
- 各种情绪词大致分布在一个**圆周**上，相邻的情绪相似，相对的情绪相反。
- 离圆心越远，情绪越强；圆心附近是中性。

```
                 arousal 高
          紧张 ·     |     · 兴奋
      愤怒 ·         |         · 高兴
  ───────────────────┼─────────────────── valence
  不愉快             |               愉快
      悲伤 ·         |         · 满足
          疲倦 ·     |     · 放松
                 arousal 低
```

图的读法：左上是"负效价 + 高唤醒"，愤怒和恐惧都落在这里；右下是"正效价 + 低唤醒"，放松、满足落在这里。

### 5.2 补维度：PAD 和 Kismet 的 AVS

二维环形模型最大的问题是愤怒和恐惧分不开。常见做法是加第三个维度：

| 模型 | 三个维度 | 第三维怎么区分愤怒和恐惧 |
|---|---|---|
| **PAD**（Mehrabian & Russell 1974） | Pleasure、Arousal、**Dominance** | 愤怒时觉得自己能掌控局面（D 高），恐惧时觉得失控（D 低） |
| **Kismet 的 AVS**（Breazeal 2003） | Arousal、Valence、**Stance** | 愤怒是趋近（S 正），恐惧是退缩（S 负） |

两者思路相同：第三维表示"我和刺激的关系"。

### 5.3 其他维度模型

按时间顺序排列：

| 模型 | 维度 | 说明 |
|---|---|---|
| **Wundt**（1896） | 愉悦–不愉悦、紧张–放松、兴奋–平静，三维 | 最早的维度模型，后来的模型基本都在继承或简化它 |
| **Watson & Tellegen**（1985），量表即 **PANAS** | 正性情感（PA）× 负性情感（NA） | 常被说成"把环形模型旋转了 45°"。这是简化说法：PANAS 本来是一张情绪自评量表，PA 和 NA 两个因子在理论上是独立的，不完全等于把坐标轴转了一下 |
| **Thayer**（1989） | 精力唤醒（energetic arousal）× 紧张唤醒（tense arousal） | 把 arousal 拆成两种：一种是有劲、清醒，一种是焦虑、紧绷 |
| **Fontaine et al.**（2007） | valence、power（掌控感）、arousal、unpredictability（不可预测性），四维 | 论文标题就叫 *The World of Emotions Is Not Two-Dimensional*；power 相当于 PAD 的 D，unpredictability 能把惊讶分出来 |
| **Lövheim 立方体**（2012） | 血清素、多巴胺、去甲肾上腺素三种神经递质，各占一个轴，8 个角对应 8 种情绪 | 发表在 *Medical Hypotheses*，**只是一个假说**，没有得到实证检验，不能和 PAD、环形模型同等看待 |

可以看出一条主线：**二维不够用，就加维度**。PAD 加 dominance，Fontaine 再加 unpredictability，Kismet 加 stance，都是为了把二维里重合的情绪分开。

### 5.4 优劣

| 优点 | 缺点 |
|---|---|
| 连续：强度、渐变、情绪转换都能自然表示 | **二维会把不同的情绪压在一起**：愤怒和恐惧都是"负效价 + 高唤醒"，坐标几乎重合 |
| 参数少（2–4 个数），方便在空间里插值，适合**动态生成** | 维度越多越准确，但越难标注、越难解释 |
| 不需要事先定好有哪些类别 | 人很难直接给 V-A 打分，标注一致性比类别差 |
| | 对设计者来说不如类别标签直观 |

## 6 Plutchik 情绪轮：离散论里加了维度结构

**出处**：Plutchik 1980，*Emotion: A Psychoevolutionary Synthesis*；通俗版见 Plutchik 2001，*The nature of emotions*（American Scientist）。

按核心假设属于 ① 离散论，但表示形式里有强度、对立这些维度结构，所以放在 ① 和 ② 之间单独讲。

### 6.1 怎么建模

- **8 种初级情绪**，排成一圈，两两相对：
  - joy（喜悦）↔ sadness（悲伤）
  - trust（信任）↔ disgust（厌恶）
  - fear（恐惧）↔ anger（愤怒）
  - surprise（惊讶）↔ anticipation（期待）
- **强度**：从轮子外圈到中心强度增加（立体看是一个圆锥），每种情绪分三级：

| 弱 | 中 | 强 |
|---|---|---|
| serenity 宁静 | joy 喜悦 | ecstasy 狂喜 |
| acceptance 接纳 | trust 信任 | admiration 钦佩 |
| apprehension 担忧 | fear 恐惧 | terror 惊恐 |
| distraction 分心 | surprise 惊讶 | amazement 惊愕 |
| pensiveness 忧郁 | sadness 悲伤 | grief 悲痛 |
| boredom 厌倦 | disgust 厌恶 | loathing 憎恶 |
| annoyance 恼怒 | anger 愤怒 | rage 暴怒 |
| interest 兴趣 | anticipation 期待 | vigilance 警觉 |

- **混合**：相邻两种初级情绪混合成复合情绪（primary dyads）：

| 组合 | 结果 |
|---|---|
| joy + trust | love 爱 |
| trust + fear | submission 顺从 |
| fear + surprise | awe 敬畏 |
| surprise + sadness | disapproval 不赞成 |
| sadness + disgust | remorse 懊悔 |
| disgust + anger | contempt 轻蔑 |
| anger + anticipation | aggressiveness 攻击性 |
| anticipation + joy | optimism 乐观 |

- **进化功能**：每种情绪对应一种适应行为，比如恐惧对应逃跑、愤怒对应攻击、信任对应亲近。Breazeal 那篇里引用的"行为稳态"就是 Plutchik 的概念，Kismet 的 fear → flee 也是这个思路。

### 6.2 优劣

| 优点 | 缺点 |
|---|---|
| 一个模型里同时有类别、强度、对立和混合 | 为什么是这 8 种、混合规则对不对，**缺少实证检验** |
| 对立关系可以直接用来做情绪仲裁：两种相对的情绪互相抑制 | 更像描述性框架，难以直接变成计算模型 |
| 情绪和行为功能挂钩，方便接到机器人的行为系统 | HRI 里用得很少：综述只找到 2 篇 |
| 词汇丰富，能覆盖次级情绪 | 8 类和主流数据集的 6/7 类对不齐（多了 trust 和 anticipation） |

## 7 ③ 评价论：情绪为什么会产生

**核心观点**：情绪来自人对事件的**评估**，不是事件本身直接引起的。同样是下雨，要去野餐的人会失望，盼着浇地的农民会高兴。

前面的 ①② 都在描述"情绪是什么样子"，评价论讲的是"**从事件到情绪**"这一步怎么算。所以它和 ①② 不冲突：评价算出来的结果，可以用类别表示，也可以用维度表示。

### 7.1 代表模型

| 模型 | 内容 |
|---|---|
| **Lazarus**（1991） | 两步评价：**初级评价**（这件事和我有关吗、是好是坏）+ **次级评价**（我能不能应对） |
| **Scherer 成分过程模型（CPM）** | 按顺序做一串检查（stimulus evaluation checks）：新奇性 → 内在愉悦度 → 目标相关性 → 应对潜力 → 规范相容性；每一步的结果都会实时改变表情和生理状态，所以情绪是一个**连续过程**，不是一个瞬间的标签 |
| **OCC**（Ortony, Clore & Collins 1988） | 按评价对象分三个分支推出 **22 种情绪**：**事件的后果**（高兴 / 不高兴 → 喜悦、悲伤、希望、恐惧、满足、宽慰、失望……）、**行动者的行为**（赞许 / 不赞许 → 骄傲、羞愧、钦佩、责备）、**物体的属性**（喜欢 / 不喜欢 → 爱、恨），再加上 4 种复合情绪（如感激、愤怒）。规则明确、容易写成代码，是 **AI 和机器人领域用得最多**的情绪生成模型 |
| **Frijda**（1986） | 强调**行动倾向（action tendency）**：情绪本质上是"准备做某事"，比如恐惧是准备逃开、愤怒是准备冲上去 |
| **Smith & Ellsworth**（1985）、**Roseman** | 各自提出一组多维评价维度，比如愉悦度、确定性、责任归属、预期努力、情境控制。可以看成"评价维度空间"，和第 5 节的情绪维度空间是两回事 |

### 7.2 和 Kismet 的对应

Kismet 的情绪系统（Breazeal 精读第 6 节）基本就是一个评价论架构：

| Kismet 的模块 | 对应的评价论概念 |
|---|---|
| releaser 判断"这件事和我当前的需求有没有关系" | Lazarus 的初级评价、Scherer 的目标相关性检查 |
| somatic marker 给 releaser 打 [A, V, S] 标签 | 评价结果用维度来表示（这一步借的是第 9 节 Damasio 的躯体标记） |
| Stance：趋近还是退缩 | 和 Frijda 的行动倾向最接近（这是我的类比，Breazeal 原文没有这样说） |
| 情绪仲裁、赢者通吃 | 最后再落回离散类别 |

### 7.3 优劣

| 优点 | 缺点 |
|---|---|
| 能解释"同一事件，不同人、不同情境，情绪不同" | 评价维度和规则要人来设计，换个场景就要重写 |
| 可以直接拿来**生成**机器人的情绪，而且有前因后果，可解释 | 很多情绪发生得非常快，未必经过有意识的评价（离散论的反驳） |
| OCC 这类模型规则明确，容易实现 | 在真实环境里，机器人很难准确知道"事件对我的目标意味着什么" |

## 8 ④ 建构论：类别是大脑临时造出来的

**核心观点**：情绪不是天生的固定类别，而是大脑临时"建构"出来的。

### 8.1 两个代表

- **Russell 核心情感**（2003）：底层只有一个随时存在的核心情感，用 valence × arousal 描述，也就是第 5 节的环形模型。"愤怒""恐惧"这些类别，是人在核心情感之上，结合认知层面的解释和归类得出来的。
- **Barrett 情绪建构论**（*How Emotions Are Made*, 2017）：大脑根据核心情感、已有的**情绪概念**和当前**语境**，预测并构造出"愤怒""恐惧"这样的类别。同样的生理状态，在考场上可能被建构成焦虑，在过山车上可能被建构成兴奋。

### 8.2 对基本情绪识别的质疑

Barrett 等人 2019 年的综述 *Emotional Expressions Reconsidered*（Psychological Science in the Public Interest）系统梳理了证据，结论大意是：

- 人在生气时确实**比平时更常**皱眉，但远不是每次生气都皱眉；
- 皱眉也可能出现在专注、困惑的时候；
- 所以"看到某种表情 → 推出某种情绪"的可靠性和特异性，远没有基本情绪论说的那么高。

这对你的项目有直接影响：

- 识别模型输出的"angry"，准确地说是"**这张脸像数据集里被标成 angry 的那些脸**"，不等于这个人真的在生气；
- 数据集里的表情大多是**摆拍**的或者夸张的，真实对话里的表情弱得多、混得多；
- 所以融合**语音、文本、语境**比只看脸更重要，你的三模态方案方向是对的。

### 8.3 和其他流派的关系

- 和 ② 维度论：建构论**接受**维度论，把 valence × arousal 当作底层。
- 和 ① 离散论：建构论**反对**类别是天生固定的，认为类别是学来的、依赖文化和语境。
- 和 ③ 评价论：两者都强调认知和语境，区别在于评价论认为"评价结果决定是哪种情绪"，建构论认为"类别本身就是大脑造出来的概念"。

## 9 ⑤ 生理 / 经典理论：身体和体验谁先谁后

这几个理论是前面各派的历史源头，争论的是**身体反应**和**情绪体验**之间的先后关系：

| 理论 | 观点 | 例子 | 留下了什么 |
|---|---|---|---|
| **James–Lange**（1884 / 1885） | 先有身体反应，再有情绪体验 | "因为发抖，所以害怕" | 情绪和身体状态密不可分 |
| **Cannon–Bard**（1927） | 身体反应和情绪体验**同时**发生，都由丘脑触发 | 看到熊，同时发抖和感到害怕 | 反驳 James–Lange：不同情绪的身体反应很相似，光靠身体分不出是哪种情绪 |
| **Schachter–Singer 二因素论**（1962） | 生理唤醒 + 认知标签 = 情绪 | 同样心跳加速，归因于危险就是恐惧，归因于心动就是喜欢 | **唤醒**这一半发展成 ② 的 arousal 轴，**认知解释**这一半发展成 ③ 评价论和 ④ 建构论 |
| **Damasio 躯体标记假说**（1994） | 身体状态给选项打上情感标签，帮助快速决策 | 想到某个选项时"心里一沉"，就倾向于不选它 | Kismet 的 [A, V, S] 打标签机制直接借用了这个想法 |

### 10.1 表示模型对比

| | FACS | 基本情绪（Ekman） | 环形模型（Russell） | Plutchik 情绪轮 |

### 10.3 选哪种表示，决定了能用哪种生成方法

| 情绪表示 / 理论 | 自然对应的生成方式（综述 3.1 节 + 补充） |
|---|---|
| ① 类别（基本情绪 / EMFACS 原型） | 每类做一个关键姿态，也就是**静态**生成。综述 Table 2 的识别率评估也是在这个框架下做的 |
| ② 维度（环形 / PAD / AVS） | 有连续空间可以插值，才能做**动态**生成和平滑转换（Kismet 在 AVS 空间里混合 9 个基础姿态） |
| FACS / 面部关键点 | **反应式**模仿时，把人脸动作搬到机器人上用的中间表示 |
| ③ 评价论（OCC、Scherer） | 决定机器人**自己的**情绪从哪来，综述的生成分类里没有这一类，Kismet 属于这一类 |

## 11 对应到机器人头项目

- **感知端**（情感识别模块）已经同时输出 7 类标签和 V/A，也就是 ① 和 ② 两套表示都有；AU 放在 `extra` 字段里。这和第 10 节的结论一致：类别用于评估和对齐数据集，维度用于后续生成。
- **按 ④ 建构论的提醒**：识别结果只能当成"这个人的外在信号像某类情绪"，不能当成真实内部状态。所以融合语音、文本和对话语境很关键，置信度低的时候宁可输出 neutral 或只用 V/A。
- **生成端**如果照 Kismet 的思路做：
  1. 用 ③ 评价论决定机器人自己的情绪：比如用简化版 OCC，根据"对方情绪、对话事件、机器人当前目标"评价出情绪；
  2. 用 ② 维度表示这个情绪：映射到 V-A-Stance 空间，用 Stance 区分愤怒和恐惧；
  3. 基础姿态用 Cogley 头**实际能做出来的 AU** 来定义，在基础姿态之间插值。
- 先列一张"Cogley 头能实现哪些 AU"的表。按 3.4 节的推断，如果做不出 AU4 和 AU20，恐惧就很可能被认成惊讶，需要靠头部后缩、视线回避这类身体线索来补。

## 12 "建模"是不是"解构"？

前面第 2–9 节的模型，可以统称为**心理学对人类情感的表征（representation）**。"解构"只是表征的一种做法，不能概括全部：

| 做法 | 含义 | 对应的模型 |
|---|---|---|
| **分解**（拆成更小的成分） | 一种情绪 = 几个成分的组合 | FACS（拆成 AU）、维度论（拆成 V、A、D 几个轴）、评价论（拆成一串评价检查）、Plutchik（复合情绪 = 两种初级情绪混合） |
| **分类**（不拆，只区分种类） | 情绪是不可再分的整体，只问"是哪一种" | 基本情绪论：它的核心主张恰恰是基本情绪是"原子"，**不能**再拆 |
| **组装**（由底层材料临时拼出） | 类别不是现成的，是大脑用核心情感 + 概念 + 语境拼出来的 | 建构论 |

所以统一说"解构"的话，基本情绪论和建构论放不进去。比较稳的说法是：**对人类情感的表征（建模）**，其中一部分模型采用"解构"的思路。07-三模态解构 里说的"解构"是指把人脸、语音、文本各自拆成特征，那个用法是准确的。

## 13 机器一侧：对应的机器情感建模方式

机器这一侧也分两层，和人类一侧对应：

- **内部状态层**：机器人"自己"现在处于什么情绪，这个情绪从哪来；
- **表达层**：这个情绪怎么变成脸、身体、声音的动作。

### 13.1 人类模型 → 机器做法

人类情感的每一种模型，在机器人上几乎都有对应的做法：

| 人类情感模型 | 机器的对应做法 | 属于哪一层 | 例子 |
|---|---|---|---|
| ① 基本情绪（离散类别） | **表情库**：每类情绪一套预制动作，状态机切换 | 内部状态 + 表达 | 大多数 NAO、Pepper 实验 |
| ② 维度论（V-A、PAD） | **情感空间**：内部状态是一个连续向量，表情在基础姿态之间插值 | 内部状态 + 表达 | Kismet 的 AVS 空间 + 9 个基础姿态 |
| FACS（AU） | **AU → 执行器映射**：每个舵机或控制点对应一个或几个 AU | 表达 | Hara 的 android 脸、各类仿真人脸 |
| Plutchik（对立、混合） | **情绪仲裁与混合**：相对的情绪互相抑制，相邻的可以叠加 | 内部状态 | Kismet 的情绪仲裁（赢者通吃） |
| ③ 评价论（OCC、Scherer） | **评价引擎**：根据事件和目标算出情绪 | 内部状态（"情绪从哪来"） | OCC 规则系统、EMA（Marsella & Gratch）、Kismet 的 releaser + 情感评价 |
| Panksepp / 驱力（动机系统） | **驱力 / 稳态模型**：内部有几个需求变量，偏离平衡就产生情绪 | 内部状态 | Kismet 的社交、刺激、疲劳三个驱力；Moerland 2018 综述里基于稳态的情绪 |
| （RL 视角） | **从价值和奖励派生情绪**：比如 TD error 为正对应喜悦、预测到负价值对应恐惧 | 内部状态 | Moerland 2018 综述的主体内容 |
| ④ 建构论（核心情感 + 语境） | **语境驱动的生成**：底层状态加上对话语境，由模型决定"现在该表现成什么" | 内部状态 | 用 LLM 根据对话推断机器人情绪（Mishra et al. 2023） |

### 13.2 表达层的其他建模方式

| 表达通道 | 建模方法 |
|---|---|
| 身体动作 | **Laban 动作分析（LMA）**：用 Effort（力度、速度、流畅度）和 Shape 描述动作的情感色彩，同一个动作做得快而重就显得愤怒、慢而轻就显得悲伤 |
| 动画质量 | 迪士尼 12 条动画原则：预备动作、慢入慢出、跟随动作、夸张 |
| 声音 | 韵律参数：音高、语速、响度（Kismet 的声音系统按 AVS 调这几个参数） |
| 非人形机器人 | 颜色、灯光、声音、运动轨迹 |
| 数据驱动 | 从人体动作重定向（retarget）到机器人，或者用生成模型 / LLM 直接生成表情动作序列 |

**规律**：人类一侧的"表征模型"，到机器一侧变成"内部状态模型"；人类一侧的 FACS 这类"测量工具"，到机器一侧变成"表达映射"。

## 14 重新划分综述的主题：机器人情感闭环

### 14.1 两种视角

Stock-Homburg 2022 的三个主题（表达、识别、反应）是**心理学视角**：机器人是"刺激"，研究对象是人。换成**工程视角**（造机器人），更自然的划分是：

- 把综述的主题 1 拆开：**机器人识别人类情感**、**机器人生成情感**；
- 把主题 2、3 合并：**人对机器人人工情感的识别和反应**。

这和 Sun & Wang 2026 的 perception / strategy / expression 分类思路一致。

### 14.2 为什么综述原来那样分

- **没有把"机器人识别人类情感"单独列为主题，是有意的。** 综述排除了 93 篇情绪识别算法论文。在 S–O–R 框架里机器人只是刺激，"识别人的情绪"只是反应式生成的一个输入，所以被放进主题 1。
- **把主题 2、3 分开，在心理学上有必要。** "认出来"和"有反应"是两个不同的变量：
  - 人可能准确认出机器人在笑，却觉得它诡异（恐怖谷），也就是识别对了，但接受度低；
  - 综述最大的批评之一，是只有 1 篇研究检验了**中介效应**（识别 → 评价 → 接受）。要检验中介效应，识别和反应必须作为两个变量分开测。

### 14.3 折中方案：五环节闭环

合并人类一侧，但内部保留两层；机器人一侧在识别和表达之间加一个"生成 / 决策"环节：

```
           ┌──────────────── 机器人一侧 ────────────────┐
           │                                            │
   ① 识别人类情感  →  ② 情感生成 / 决策  →  ③ 情感表达
   （FER/SER/TER）   （内部状态、评价、     （AU 映射、插值、
                      该回应什么情绪）       动作、声音）
           ▲                                            │
           │                                            ▼
   ⑤ 人的反应      ←      ④ 人对机器人情感的识别
   （态度、行为、          （认不认得出）
    接受度）
           └──────────────── 人类一侧 ──────────────────┘
```

图的读法：

- 上排是机器人做的事，下排是人做的事，首尾相连，就是综述 Fig. 7 说的"带反馈回路的控制论框架"。
- "情感生成"拆成 ②（决定要表现什么情绪）和 ③（怎么把它做出来），分别对应 13.1 节的内部状态层和 13.2 节的表达层。
- ④⑤ 合起来是"人类一侧"，但仍分两层，方便以后做用户实验时检验中介效应。
