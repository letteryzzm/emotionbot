## 二、今天踩的坑与修复

| 问题 | 现象 | 修复 |
|---|---|---|
| transformers 5.x | 启动时提示 `PyTorch >= 2.6 is required but found 2.5.1`，模型全部不可用 | 锁 `transformers==4.57.6`，写进两套安装脚本 |
| funasr 安装失败 | `emotion2vec` 不是 PyPI 包，和 funasr 写在一条命令里导致整条失败 | 拆成 `funasr` 和 TTS 两条命令 |
| Windows 证书库损坏 | `import edge_tts` 抛 `ASN1: NOT_ENOUGH_DATA` | `ensure_ssl_context()` 用 certifi 兜底 |
| PowerShell 读脚本乱码 | 无 BOM 的 UTF-8 被按 GBK 解析，字符串未终止 | 脚本改存 UTF-8 with BOM |
| `-ExecutionPolicy Bypass` | 被安全策略拦截 | 移除该参数，改用 `powershell -NoProfile -File` |
| GBK 控制台 | 打印特殊字符直接崩溃 | stdout/stderr 统一 reconfigure 为 UTF-8 |
| FunASR 缺 fbank 后端 | `ImportError: torchaudio is not installed` | 安装匹配版本的 `torchaudio==2.5.1+cu121` |
| emotiefflib 预热失败 | `No module named 'timm'` | 安装 `timm` 并加入依赖 |
| 蓝牙串口 | 枚举到 4 个蓝牙 COM 口，逐个探测超时 | 跳过 `vid is None` 的端口 |
| 状态卡死 | 矛盾事件后 EMA 过重，后续情绪切不回来 | 峰值 ≥0.6 时 α 提到 0.75，矛盾事件透传 |
