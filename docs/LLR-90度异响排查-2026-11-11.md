## 2026-11-11 的隔离处理（历史）

- `scripts/tune_server.py` 的 `BLOCKED` 暂时禁用 LLR，EXA 仍为禁用备用通道。
- 单独通电、下唇整组通电、保持 90°、小步调整、加载和重放含 LLR 的姿态都会被拒绝。
- 整段动作在执行第一步前检查，避免先动其他电机再发现 LLR 被禁用。串口发送入口也有检查；旧页面或直接 API 请求不能绕过。
- 页面显示 LLR 锁定原因，刷新后相关通电按钮不可用。其他组可继续操作，全部卸力仍可用。
- 不修改 LLR 中心、运动范围、PWM 频率或固件，不把 90° 改成另一个未经验证的角度。
- 此隔离作用于当前标定服务。旧 hub 的“下唇固定 90°”逻辑及其他直连串口脚本没有跟随此次修改，排查期间不要启动它们。

## 现场排查顺序

1. 全部卸力后确认声音是否消失；若仍持续响，断开舵机 5V 电源。
2. 断开 5V 后检查右下唇连杆：是否顶住外壳、安装偏斜、关节卡滞，或舵盘安装角度使中位持续受力。不要带电硬扳舵机轴。
3. 断电拆开 LLR 与下唇机构的连接，使输出轴不带连杆负载。完成后再安排单轴短时测试；当前软件锁定期间不发送此测试动作。
4. 若空载安静、装回后响，优先查连杆装配与受力；若空载仍响，再检查舵机本体、接插件、供电与控制信号。仅凭声音不能确定堵转或舵机损坏。
5. 排除故障并重新验证单轴中心与小范围行程后，才解除 LLR 锁定，重新保存包含它的 neutral 和表情。

依据：Pololu 技术支持建议通过脱离机械负载区分负载引起的嗡嗡声；其接口说明也指出，名义中位脉宽不保证处于每只舵机的实际机械中点。这里据此提出排查步骤，并未确认本机故障原因。[负载与异响排查](https://forum.pololu.com/t/micro-maestro-and-jitter/4975)，[舵机脉宽与中位说明](https://www.pololu.com/blog/17/servo-control-interface-in-detail)。

本次通过 `--llr-unloaded` 启动标定服务，页面增加“LLR 90° · 1 秒后卸力”按钮。常规 LLR 故障锁定仍保留；仅此诊断动作允许 LLR 到 90°，随后自动卸力，Esc 可提前结束。服务启动不会触发检查，用户自行点击。此选项只适用于已拆舵盘、轴无外部负载的阶段，复装前停止该模式。

操作顺序：

1. 保持舵盘脱离、舵机本体固定，手和工具离开输出轴；确认能立即断开舵机 5V。
2. 打开标定台，接通舵机 5V，点击一次专用空载检查按钮。
3. 记录是否转到一个稳定位置、是否嗡嗡响或抖动，以及自动卸力后声音是否停止。无舵盘时转动可能不易看清，可记录“看不清”，不要带电用手捏轴。
4. 空载安静则优先检查装配受力；空载仍响则继续查舵机、接线和供电。无论哪种结果，都不直接视为完整范围验收通过。

软件验证：本地与 ROG 各 95 项相关测试通过，浏览器仿真已验证自动卸力。**真实空载声音与运动结果仍待用户反馈**，尚未改写中心或范围。

这次采用带载与空载对照，原因是拆除外部负载后可缩小故障范围。现场描述、测试条件和日志将作为判断依据，软件测试不等同于机械合格结论。

因此，上次不能仅凭动作和命令成功视为全部机械标定通过。现有资料无法判定这次问题是当时漏检，还是之后出现 / 加重。验收缺少必须填写的声音、静态保持和温升观察项，也缺少异常关闭证据，这是流程需要补齐的地方。软件仿真测试不提供这些物理观测。

待验证原因分为：舵机位置反馈或内部控制问题；齿轮 / 壳体 / 安装压迫等内部机械阻力；舵机端供电、接插件和地线问题；控制脉冲完整性问题。当前代码名义输出 50 Hz、90° 对应约 1500 μs，尚未测量实际引脚波形或舵机电流，不能排除电气原因。

建议先以同型号正常备用舵机做对照：断开 5V 后，只替换 LLR 接口上的空载舵机，保持供电和命令条件相同。备用安静则问题偏向原舵机、自带线或安装条件；备用同样异常则检查该通道和电源，并用正常通道 / 电源进一步分离。该对照尚未执行，用户有无正常备用舵机待确认。

### 螺丝与是否可继续使用：当前判断

没有证据表明是拧舵盘螺丝太用力把舵机内部拧坏。此前“安装压迫”只是待验证假设，还应区分舵盘固定螺丝、外壳螺丝与支架夹持；不能仅凭空载嗡嗡声倒推安装损坏。

声音说明通电保持时存在可听振动；它本身不能区分正常维持位置与异常持续纠偏。要判断能否继续使用，先短时观察能否稳定到位、是否抖动或很快异常升温；以同型号正常舵机在同一供电与通道上的结果作对照。有仪器时记录舵机端电压、保持电流与温度变化。若出现明显抖动、卡滞、失步、快速异常温升或电流显著偏高，应停止该通道的使用并定位原因。

只有基线观察稳定后，才安排小范围往返与多次回位，例如从 90° 附近逐步探索，而不是直接扫完整行程；随后再验证实际机构负载与使用时长。这个顺序是建议的验证路径，尚未对真实 LLR 执行，不能据此认定它已可长期使用。当前 LLR 隔离保持，下一步优先做同型号空载对照。

新版[标定台 v2](舵机标定台-v2.md)已把指令与人工观察分开记录，声音、到位、抖动、发热不会由串口 OK 自动标为通过。一般通道可执行慢速范围探索；LLR 仍仅限专用 90° 检查，界面可选择保持时长并写入观察日志。
