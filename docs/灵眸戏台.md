# 灵眸戏台

给一张京剧或动漫图片，千问全模态模型选出动作，2D 脸和真机一起演。

```bash
.venv/bin/python -m culture.server        # http://127.0.0.1:8790
```

样图的识别结果已保存，不联网也能演；右边的动作也可以手动点。

## 接真机

戏台在 Mac 上运行，这样识图密钥不用放到 ROG 的共用目录。

```bash
ssh -L 8780:127.0.0.1:8780 rog            # ROG 上先运行 head.hub_server 并连接真机
```

勾选“同步到真机”后，动作进入控制进程的 `dialog` 层，标定范围、下巴成对和失联保护都照常生效。网页手动表情的优先级更高，要先点“交还自动控制”。

## 识图

默认用阿里云百炼的 `qwen3.8-omni-flash`，读取 `emo_bench/.env` 里的 `DASHSCOPE_*`。上传的图片缩到 768 px、去掉元数据后才发送，结果缓存在 `outputs/culture_cache/`。

换接口时设置这三个环境变量，接口要兼容 OpenAI 流式调用：

```bash
CULTURE_API_BASE=... CULTURE_API_KEY=... CULTURE_MODEL=... .venv/bin/python -m culture.server
```

魔搭 API-Inference 在 2026-11-07 公开列出的 38 个模型里没有 Omni 全模态模型，所以没有默认用魔搭。

## 实测

22 张 Wikimedia Commons 图片，人工核对：

| 项目 | 结果 |
|---|---|
| 类别判断 | 22 张全对，包括 2 张无关图片 |
| 有明确预期的动作 | 10 张全对 |
| MediaPipe 对照 | 47 张只检出 11 张，已弃用 |

样本少，标注也是开发时自己做的，只能说明方向可行。模型返回的把握几乎都是 1.0，不能当准确率看，所以网页不显示。

## 限制

- 只有眼、眉、嘴能动，水袖、身段、翎子功都做不了。
- 脸谱颜色只显示在 2D 画面里。
- 脸谱颜色的含义是常见说法，不是所有角色都适用。
- 动作是按公开的行当常识编的，没有请戏曲老师看过。
- 动作只在 2D 画面里验证过，舵机幅度和速度要在真机标定后再调。

## 真机演出

播放器必须和控制进程在同一台机器上。Mac 经 Tailscale 到 ROG 的延迟最高到过 210 ms，每帧隔网发送时，演到一半意图会过期，脸塌回待机。

在 ROG 上：

    cd /srv/robot-head
    .venv/bin/python -m head.hub_server --allow-unverified --speed 600
    .venv/bin/python -m culture.server --port 8790

`scripts/tune_server.py` 占着三块板的串口，要先停掉。两个服务起来后，控制台点上电，或者向 `/api` 发 `{"op":"arm"}`。

在 Mac 上：

    ssh -fN -L 8780:127.0.0.1:8780 -L 8790:127.0.0.1:8790 rog

打开 http://127.0.0.1:8790 看戏台，勾“同步到真机”，点图片就演。控制台在 http://127.0.0.1:8780，急停也在这里。

- `--allow-unverified` 下范围以 `firmware/config_*.py` 为准，不再用 `tune_log` 里较窄的旧实测值。
- 下唇 LLL、LLR 固定 90°，EXA 不驱动。
- ROG 上没有识图密钥和 opencv，上传图片会报错，预设图片不受影响。

## 视觉和语音接到真机

三路都发给同一个控制进程，分层叠加：

| 层 | 来源 | 动什么 |
|---|---|---|
| `vision` | `camera.hub_source` 读 `camera.web` 的 `/state` | 眼球跟人，表情随距离变（>1.5 m 犯困，0.45–1.5 m 感兴趣，0.28–0.45 m 皱眉，<0.28 m 害怕，晃太快受惊） |
| `dialog` | `scripts/rog_voice.py` 的回复情绪，或戏台动作 | 语音只写表情不写眼球，说话时眼睛继续跟人；戏台全身接管 |
| `lips` | TTS 音量包络 | 下巴，按声音实际播放的时刻动 |

在 ROG 上：

    cd /srv/robot-head
    .venv/bin/python -m camera.hub_source
    PYTHONPATH=. tools/voice_test/.venv/bin/python scripts/rog_voice.py --listen 127.0.0.1:8767

`camera.web` 要开着，它占摄像头。语音和戏台共用 `dialog` 层，一个结束时会清掉另一个的表情。

## 灵眸总控

平时只需要启动这一个，它会拉起控制进程、戏台、语音，并按模式开关摄像头和跟踪：

    cd /srv/robot-head && .venv/bin/python -m lingmou.server

Mac 上 `ssh -fN -L 8800:127.0.0.1:8800 rog`，控制台 http://127.0.0.1:8800 ，演示页 http://127.0.0.1:8800/demo 。

| 模式 | 摄像头和跟踪 | 听麦克风 | 戏台接真机 | 待机动作 |
|---|---|---|---|---|
| 待机 | 关 | 暂停 | 否 | 开 |
| 视觉跟随 | 开 | 暂停 | 否 | 开 |
| 语音对话 | 关 | 听 | 否 | 开 |
| 全互动 | 开 | 听 | 否 | 开 |
| 戏台 | 关 | 暂停 | 是 | 开 |
| 手动 | 关 | 暂停 | 否 | 关 |

- 全部卸力（`Esc`）后回到待机，同时关摄像头、停戏台、暂停听。
- 视觉参数存在 `outputs/lingmou.json`，改了只重启受影响的服务。
- 摄像头按名字找设备号，拔插后号变了也能找到。画面 5 秒不更新会自动重启 `camera.web`。
