眼部传动与组装

方向约定：“前”是眼睛朝向，“左/右”是面对机器人时的左右手。依据官方 EyeMech ε3.2 说明书、官方 3mf 和 STL 实测；标“推断”的地方来自几何分析，还没有在实物上验证。

1. 眼球怎么动

两只眼球靠两根横梁连成一组，只用 2 个舵机：LR 管左右，UD 管上下。LR 舵机本身也跟着整组一起上下摆。

先记住这个结构：每只眼球背面卡着上下两片 EyeAdaptor。下片套在 X 轴件 A 的销柱上，这是眼球的左右转轴。上片带尾柱，接 LateralFrame，负责把力传给眼球。

左右传动（LR）

LR 舵机 → CentralServoHorn → LateralFrame → 两片上 EyeAdaptor 的尾柱 → 两只眼球

舵盘臂和 EyeAdaptor 的尾部臂都约 15 mm，三个环的中心距是 37.5 mm，和两只眼的转轴间距一致，组成平行四边形。舵盘一转，LateralFrame 横向平移，两只眼转过相同的角度。

上下传动（UD）

UD 舵机 → VerticalHorn → VerticalLever → Y 轴支架 → 整个眼球核心

Y 轴支架 EyeCorePivotHolder 左右两根销轴插在两个 Base_v2 的环里，这是上下转轴。支架上有一根力臂，卡柱在转轴上方 17 mm；UD 舵盘臂也是 17 mm。连杆一拉，Y 轴支架连同 LR 舵机、A、LateralFrame 和两只眼球一起上下摆。

2. 先组 3 个子组件

子组件零件怎么组
X 轴 AEyeCorePivotHolder_v2 + 2×EyeAdaptor_v2两片压到 A 两端销柱上，V 形尖朝前，要能自由转
X 轴 BLateralFrame + CentralServoHorn + 2×EyeAdaptor有小圆点的一面朝上；两端环套 EyeAdaptor 尾柱，中环套舵盘卡柱
Y 轴EyeCorePivotHolder + VerticalLever + VerticalHorn连杆前环套到力臂卡柱上，舵盘卡柱穿进连杆后环，不拧螺丝

3. 组装流程

  1. 装 LR 舵机。A 平面朝上、销柱朝下。舵机放进方框，输出轴朝上并靠前，线从缺口出去，耳朵落在 A 的上平面位置。
  2. 扣 Y 轴。Y 轴支架从舵机上方扣下，卡钩钩住 A 的方框，把舵机夹住。力臂在左侧。
  3. 装中心枢轴座。两个 Base_v2 的环分别套上 Y 轴左右销轴，有一点阻力，装好后要转动顺滑。
  4. 松装 X 轴 B。整组放到 LR 舵机轴上，先不拧舵盘螺丝，校准时还要提起来。
  5. 卡进底板。两个 Base_v2 从底板 SnapEyemech_v20 下面往上卡。
  6. 压眼球。每只眼球从前面压到上下两片 EyeAdaptor 的 V 形翼上，卡进背面凹槽。轻轻左右拨，两只眼应该一起动。
  7. 装眼皮。连杆先从外侧套到眼皮卡柱上（上眼皮 LidBR 配短杆，下眼皮 LidTR / LidTR_v2 配长杆）。上下眼皮对齐后一起插进中心枢轴，可以掰一下机构，或把眼球转到一侧。内侧顺序：Base_v2 → 下眼皮耳 → 上眼皮耳。
  8. 装外侧枢轴。两个 Base 从底板下面卡上，Ø6 销穿过两片眼皮的外耳。外侧顺序：上眼皮耳 → 下眼皮耳 → Base 板。
  9. 放 5 个舵机并扣压扣。TL、TR 竖放，轴朝外、在上端，机身向下穿过底板；BL、BR 平躺，长边前后方向，轴在后端；UD 竖放，轴朝左。两个 SnapEyemech_v20_v2 各压一侧的眼皮舵机，SnapEyemech_v20_v3 压 UD。
  10. 通电回中，逐个校准。运行 .venv/bin/python scripts/servo_check.py --center，全部转到 90° 后按下表装舵盘。
  11. 检查。断电后轻推全行程，确认没有卡点，再用 M3×8 把底板装到头骨框架上。

4. 校准（舵机在 90°）

舵机操作应有状态
LR提起 CentralServoHorn，不用拆 LateralFrame。眼球摆正，压回花键，拧螺丝舵盘臂朝正后，两眼朝前
UD取下压扣拿出舵机，把轴压进 VerticalHorn，拧螺丝后放回。记住原来的位置和朝向舵盘臂朝正上，两眼朝前
TL / BL / TR / BR眼皮合到中间，舵盘从外侧同时压进连杆后环和舵机轴，再拧螺丝舵盘臂向眼球倾斜约 20°，上下眼皮闭合

差一个齿时，拔下舵盘换齿位，不要掰连杆。还差一点再改 firmware/config_eyes.py 的范围。

5. 容易装错的地方

现象原因处理
眼球压不到底A 上下装反，端环顶到眼球壳壁翻成平面朝上、销柱朝下
两只眼不一起转上片 EyeAdaptor 没接 LateralFrame，或漏装每只眼要上下 2 片，共 4 片
UD 连杆套不上舵机固定后才接连杆，两头都要轴向套（推断）先在 Y 轴子组件里接好
眼皮连杆套不上舵盘舵盘先压上了轴，卡柱朝向舵机（推断）先装连杆，舵盘最后从外侧压
一侧上眼皮或外侧 Base 对不上STL 导出时丢了镜像，打成两个同手性的件两件面对面应能镜像对合；不能的话用原版 3mf 重打
