有可调电源就设 5.0 V、限流 0.3 A，电流顶到限流就马上关。

第一次接舵机

  1. 眼睛板、嘴部板的开关拨到校准档，插好 Pico。这时舵机全部保持 90°。
  2. 先接 5V，再插 USB。断电时先拔 USB。眼板、眉板只插 USB 时，电会从 Pico 倒灌到舵机那一路，电脑 USB 带不动。
  3. 眼睛板只接 LR。开关拨回运行档，舵机继续停在 90°。运行： 
    cd /Volumes/Robotics/projects/head
.venv/bin/python scripts/servo_step.py
> LR=110
    面对机器人看眼球往哪边转，到这里选结果。转完发 LR=90。
  4. 其余舵机一次接一个，断电插线。上电时开关同样先在校准档，再拨回运行档。
  5. 照下面的动作表走 5–10° 小步。听到嗡嗡响就马上输入 X 卸力。
  6. 全部通过后，才能在运行档上电或发 R。最后用 .venv/bin/python scripts/servo_check.py 全部扫一遍。
眉毛板没有校准开关，上电直接转到 rest，只离 90° 约 10°，问题不大，也是一次接一个。

不对怎么改

现象怎么改要不要重刷
LR 测试眼球转向你的左手边上面选"左手边"，表和图自动换。把 head/actuators.py 的 ANGLE_UP_IS_CCW 改成 False不用
某一对方向反了（比如 TL 往闭的方向走）马上 X，断电，对调这一对的插头不用
只有一个反，它的另一半是对的先查舵机是不是放反了、连杆是否接错。不要只改一边的角度看情况
90° 时位置不对，差一点拔下舵盘或连杆错一齿。别掰不用
不到范围就顶死、嗡嗡响X 卸力，慢慢试出极限，在 firmware/config_*.py 里把 a 或 b 收回，留 5°要，firmware/flash.sh eyes（brows / mouth）
舵机抖或不动量该列 + − 电压，看插头有没有插反，检查 S 列焊点不用
Pico 反复重启舵机太多同时动导致掉压：查 XT60 和 DC 接头，电源是否真有 5V 10A不用

注意事项

  • 绝对不要接 12V。眼眉板上有 12V 字样，但舵机直接接在电源上，会烧。
  • Pico 插反、XH 反接都能烧板。上电前再看一次 USB 朝向：USB 朝 H1 第 1 脚那一端，嘴部板插里侧两排。
  • 嘴部板 BOARD POWER 要插跳线帽，否则 Pico 没有电。
  • 插拔舵机都要先断电。
  • JL、JR 是硬连在同一个下巴上的。第一次只接一个，确认方向后再接另一个，否则两个舵机会对顶，大电流还可能打坏 JawLink。
  • EXA 不接。眉毛板 4、5 列空着。
  • 舵机线先别扎死，全部通过后再走线，转到两端看线有没有被连杆夹住。
  • 整机跑起来后摸 DC 插头和端子，发烫就停。后盖封死以后再测一次温度。
