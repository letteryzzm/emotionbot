# 07 三模态解构与情绪体系

> 日期：2026-10-20
> 内容：情绪用什么标签表示（三模态共用），人脸 / 语音 / 文本各自从信号里拆出什么，以及工程上怎么拼起来
> 相关：[README.md](README.md)（统一输出接口 `EmotionEstimate`）、[06-实验报告.md](06-实验报告.md)（文中引用的实验数字）

分两层看：

- **输出层**：情绪用什么标签表示。三个模态共用一套。
- **输入层**：每个模态从信号里拆出哪些可测量的东西。三个模态各不相同。

---

## 1. 情绪本身的分类体系（三模态共用）

| 体系 | 定义方式 | 具体内容 | 工程里用在哪 |
|---|---|---|---|
| **离散基本情绪（Ekman）** | 少数人类普遍共有的类别 | 6 类：happy / sad / angry / surprise / fear / disgust，加上 neutral 成 7 类 | 最常用。我们的统一 7 类就是这个；FER2013、RAF-DB、DFEW、MELD、M3ED、SenseVoice 都是这 7 类 |
| Ekman 扩展 | 再加一类 | 加 contempt（轻蔑）成 8 类 | AffectNet |
| **Plutchik 情绪轮** | 8 种基本情绪，两两组合成复合情绪，还分强度 | 如 joy + trust = love | 偏理论，偶尔用来设计标签 |
| 细粒度类别 | 按语料里实际出现的情绪定类 | GoEmotions 27 类 + neutral；CPED 13 类 | 文本领域常见，用时要映射回 7 类 |
| **维度模型（Russell 环形模型）** | 情绪是连续空间里的一个点 | **Valence 效价**（愉快 ↔ 不愉快）和 **Arousal 唤醒度**（激动 ↔ 平静），取值 [-1, 1] | AffectNet、Aff-Wild2、IEMOCAP、MSP-Podcast 有这种标注 |
| PAD / VAD 三维 | 在 V/A 上再加一维 | **Dominance 支配度**（掌控 ↔ 被压制），用来区分 angry（高支配）和 fear（低支配） | IEMOCAP、NRC-VAD 词典 |
| 情感极性（sentiment） | 比情绪更粗 | 正面 / 负面 / 中性，或细分 5 级 | 文本领域，如 SST、CPED 的 sentiment 字段 |
| 评价理论（appraisal，如 OCC、Scherer） | 按"对事件的评估"推导情绪 | 如"目标受阻 + 有人为责任 → 愤怒" | 工程里很少直接用；适合机器人自己"产生"情绪时参考 |

离散类别和 V/A 可以互相换算，比如 angry ≈ 低 V、高 A，sad ≈ 低 V、低 A。所以统一接口是 **7 类概率 + 可选 V/A**。

## 2. 人脸（FER）

**处理流程**：人脸检测 → 对齐（用 landmark 摆正）→ 选出正在说话的人（active speaker）→ 提取特征 → 分类。输入是单张图叫静态 FER，是一段视频叫动态 FER（DFER）。

**人脸能拆出四种表示**：

| 表示 | 是什么 | 例子 / 工具 |
|---|---|---|
| **表情类别** | 直接输出 7 类或 8 类 | EmotiEffNet、DFER-CLIP |
| **FACS 动作单元（AU）** | Ekman 定义的面部肌肉动作编码，约 44 个 AU，强度分 A–E 五级。只描述"哪块肌肉在动"，不直接说是什么情绪 | AU6 + AU12 = 真笑（Duchenne smile，眼角也皱）；只有 AU12 = 礼貌性假笑；AU4 = 皱眉；AU1 + AU2 = 抬眉（惊讶）。工具：OpenFace、Py-Feat |
| **V/A 连续值** | 回归效价和唤醒度 | AffectNet、Aff-Wild2 |
| **几何特征** | 68 个 landmark 点，加头部姿态、视线、眨眼 | 传统方法（HOG / landmark + SVM） |

**三个工程难点**：

- **摆拍和真实场景差别很大**：RAVDESS 上分数很高，MELD 上接近随机（06 第 2.2 节）。
- **说话时嘴部在动**，干扰表情判断。
- **画面里最大的脸不一定是说话的人**。

**对机器人头的意义**：机器人头的舵机本身就相当于"肌肉"。L1 模仿阶段可以把人的 AU 直接映射成舵机动作，比先识别"高兴"再生成动作更细。

## 3. 语音（SER）

**先把一段语音拆成三部分**：

| 部分 | 内容 | 交给哪个模块 |
|---|---|---|
| 说了什么 | 语言内容 | 转成文字后交给 TER |
| **怎么说的** | 副语言（paralinguistic）信息 | **SER 只负责这一部分** |
| 谁在说 | 说话人身份 | 说话人识别；也用于按说话人划分训练 / 测试集 |

**声学特征的维度**：

| 维度 | 具体特征 | 和情绪的关系 |
|---|---|---|
| **韵律（prosody）** | 音高 F0（均值、范围、起伏）、能量 / 响度、语速、停顿 | 愤怒和高兴时 F0 高、起伏大；悲伤时 F0 低、语速慢 |
| **音质（voice quality）** | jitter（音高抖动）、shimmer（振幅抖动）、HNR（谐噪比）、气声 / 紧张声 | 恐惧时声音发抖，悲伤时气声多 |
| **频谱** | MFCC、共振峰（formant）、频谱斜率 | 反映声道紧张程度 |
| 标准特征集 | **eGeMAPS 88 维**：以上三类的精选组合 | 06 里"第 1 代"基线 |
| 自监督表示 | WavLM、emotion2vec 的隐层向量 | "第 2 代"；探针测的就是这些表示 |

**标签维度**：

- **类别**：RAVDESS 8 类（比 7 类多 calm），CREMA-D 6 类，ESD 5 类。
- **强度**：RAVDESS 分 normal / strong 两级，CREMA-D 分 4 级。
- **维度**：IEMOCAP、MSP-Podcast 有 V/A/D 标注。
- **非语言发声**：笑、哭、叹气、咳嗽。SenseVoice 作为"事件"单独输出。

**关键经验：语音和人脸互补。**

| | 擅长 | 不擅长 |
|---|---|---|
| 语音 | 唤醒度（愤怒 vs 平静好分） | 效价（高兴和愤怒都高音调、高能量，易混） |
| 人脸 | 效价（开不开心） | 唤醒度 |

06 第 2.1 节的维度检验（RAVDESS）：人脸 valence AUC 99.9、语音 valence 71.2；语音 arousal 87.6。这就是融合在 RAVDESS +5.2、CREMA-D +7.1 UA 的根本原因。

## 4. 文本（TER）

**任务按粒度从粗到细**：

| 层次 | 任务 | 标签 | 数据集 |
|---|---|---|---|
| 1 | **情感极性分析** | 正 / 负 / 中，或 5 级 | SST、CPED 的 sentiment 字段 |
| 2 | **情绪分类** | Ekman 7 类或细粒度类别 | MELD 7 类、M3ED 7 类、CPED 13 类、GoEmotions 28 类 |
| 3 | **方面级情感（ABSA）** | 对某个对象的情感，如"屏幕好但电池差" | SemEval |
| 4 | **对话情绪识别（ERC）** | 结合上下文和说话人判断当前句 | MELD、CPED；06 的 LoRA 用前 8 轮做上下文 |
| 5 | 情绪原因 / 意图 | 情绪原因抽取（ECE）、对话行为（DA）、性格（Big Five） | CPED 标了 DA 和 Big Five |

**特征的三代方法**：

1. **情感词典**：NRC EmoLex、NRC-VAD；中文有大连理工情感词汇本体。
2. **上下文向量**：TF-IDF、RoBERTa embedding。
3. **大模型推理**：直接让 LLM 判断。

**难点**：

- **反讽**：字面和真实情绪相反。
- **隐式情绪**："我考完了。"没有情绪词，要靠上下文。
- **ASR 错误**：语音转文字出错直接拖低分数，06 实测损失 13–18 macro-F1。

## 5. 工程上怎么拼起来

1. **统一输出**：三个模态都输出 `EmotionEstimate`（见 README）：7 类 + other 的概率、可选 V/A、置信度。
2. **时间对齐**：以 VAD 切出的一句话为时间窗。
   - 窗内人脸逐帧结果加权平均。
   - 语音、文本每句一个结果。
   - 某个模态缺失（如没拍到脸）时，融合直接跳过它。
3. **分工**：

   | 模态 | 主要负责 |
   |---|---|
   | 人脸 | 效价；不说话时的状态 |
   | 语音 | 唤醒度；笑、哭等事件 |
   | 文本 | 语义、原因、对话上下文 |

4. **标签是按什么标注的**（容易忽略）：
   - MELD 的标签是标注员看完整视频（画面 + 声音 + 文字）后给的。单独用某一个模态时，那个模态里不一定真有对应线索。这也是 MELD 上 FER 分数很低的原因之一。
   - CREMA-D 分别给了"只听声音"、"只看画面"、"音视频一起"三套评分，可以看出每个模态单独能传达多少情绪。
