# 04 最终展示设计

> 目标有两个：一是证明**熟悉 FER / SER / TER 的主流方法**（知道有哪几代方法、各自强在哪、弱在哪）；二是证明**能把它们用起来**（在真实机器人和中文对话里跑通，并且量化出效果）。
> 所以展示分成三件：**一张 benchmark 大表**（熟悉度）、**一个实机 demo**（应用能力）、**三张消融图**（理解深度）。另外配一份技术报告和一段视频把它们串起来。

---

## 交付物 1：主流方法对比大表（"三代方法 × 三个模态"）

同一套评测集上，每个模态跑三代方法，外加融合方法。每个格子是 macro-F1 / UAR，并附推理延迟。

| 模态 | 第一代：手工特征 + 浅层模型 | 第二代：自监督 / 专用预训练 | 第三代：大模型 |
|---|---|---|---|
| **FER** | MediaPipe landmark（或 HOG）+ SVM | EmotiEffNet-B0（静态）· MAE-DFER / DFER-CLIP（动态视频） | VLM zero-shot（如 Qwen-VL 系列，云上） |
| **SER** | eGeMAPS / MFCC + SVM（openSMILE） | emotion2vec+ 线性头 · audeering w2v2（V/A） | SenseVoiceSmall 一体化 · Qwen-Omni 纯音频输入 |
| **TER** | 情感词典 / TF-IDF + LR | Chinese RoBERTa 微调（单句） | LLM zero-shot / few-shot（带对话上下文）· Qwen 7B QLoRA（InstructERC 风格） |
| **融合** | 特征拼接（early fusion） | 置信度加权 late fusion · MERTools baseline | LLM 融合（三路结果 + ASR 文本给 LLM）· Qwen-Omni 端到端音视频 |

**评测集**：M3ED 测试集（三模态通用）+ 每个模态一个标准集（03 的 B 组）+ 自采集（03 的 C2、C3）。

**这张表要回答的问题**（写在报告里）：
1. 每一代比上一代提升多少？提升主要在哪几类情绪上？（预期：fear / disgust 这类少数类提升最大）
2. 大模型 zero-shot 和专用小模型比，谁更好？延迟差多少？能不能上机器人？
3. 融合在哪些情况下有用、哪些情况下反而变差？

## 交付物 2：实机 demo（"机器人看得懂你的情绪"）

### 场景

用户坐在机器人头前面，用中文和它聊天。屏幕上有一个本地网页仪表盘（自己托管，不发到外部平台），机器人头根据融合结果做表情回应（对应 `复现计划.md` 的 L3）。

### 仪表盘布局

```
┌───────────────────────────┬───────────────────────────────┐
│ 摄像头画面 + 人脸框 + AU 条 │  实时时间线（最近 60 秒）           │
│                           │  face   ▇▇▅▅▃▃ happy → neutral   │
│                           │  speech ▇▇▇   angry              │
│                           │  text   ▇▇▇   happy ("太好了")    │
│                           │  fused  ▇▇▇   angry  ⚠ 矛盾       │
├───────────────────────────┼───────────────────────────────┤
│ ASR 文本（SenseVoice）      │  V/A 二维散点（当前点 + 轨迹）       │
│ 延迟：FER 12ms / SER 180ms │  机器人当前表情：concerned           │
└───────────────────────────┴───────────────────────────────┘
```

### 演示脚本（约 3 分钟）

| 段落 | 演示内容 | 展示的能力 |
|---|---|---|
| 1. 三路分开看 | 只做表情不说话 → 只有 face 有输出；背对镜头说话 → 只有 speech / text | 模块独立、缺失模态处理 |
| 2. 一致情况 | 笑着说"今天特别开心" | 三路一致，融合高置信度 |
| 3. **矛盾情况** | 皱着眉、用无奈的语气说"太好了，又要加班" | 文本说 happy，语音和表情说 angry/sad，融合跟语气走并标出"矛盾"——**这是整个 demo 的亮点** |
| 4. 机器人回应 | 机器人头根据融合结果做出关切的表情 | 感知到表达闭环（L3） |
| 5. 干扰 | 机器人自己说话、舵机在动 | TTS 期间不误触发，舵机噪声下仍能识别 |

## 交付物 3：三张消融图（"知道为什么"）

| 图 | 横轴 / 纵轴 | 要说明的结论 |
|---|---|---|
| **图 1：ASR 误差对 TER 的影响** | 横轴：输入文本来源（标注文本 / SenseVoice 转写 / 人为加噪声 CER 10%、20%）；纵轴：TER macro-F1 | TER 在机器人上的真实性能取决于 ASR；LLM 是否比 RoBERTa 更抗 ASR 错误 |
| **图 2：静态 vs 动态 FER** | 横轴：时间窗长度（单帧 / 0.5 s / 1 s / 整句）；纵轴：FER UAR；两条线：逐帧 EmotiEffNet 平均 vs 视频模型 MAE-DFER | 时间信息到底值多少；实时场景用"逐帧 + 平滑"够不够 |
| **图 3：模态贡献** | 每组柱子：一种情绪类别；柱子颜色：face / speech / text / fused 的召回率 | 哪个模态擅长哪类情绪（预期：表情擅长 happy/surprise，语音擅长 angry/sad 的唤醒度，文本擅长有明确情绪词的句子） |

每张图在报告里都配一段说明：画的是什么、坐标轴和颜色的含义、怎么读、数字来自哪次实验。
