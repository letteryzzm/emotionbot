# 03 验收标准

> 原则：每一条都能用一个脚本跑出一个数字，和阈值比较，给出"通过 / 不通过"。
> 阈值分两种：**复现类**以论文数字为锚点；**自采数据类**是第一版目标值，拿到 baseline 后如果明显不合理，要写明理由再调整，不能悄悄改。
> 指标约定：7 类分类报 **macro-F1** 和 **UAR**（unweighted average recall，各类召回率的平均，类别不平衡时比准确率可靠）；SER 按领域惯例同时报 UA / WA；V/A 报 **CCC**（一致性相关系数，-1 到 1，越高越好）。随机猜 7 类的 UAR 是 14.3%。

---

## A. 功能完整性（必须全部通过）

| 编号 | 标准 | 怎么验 |
|---|---|---|
| A1 | 三个模块都输出统一的 `EmotionEstimate`（见 README），probs 和为 1，时间戳单调 | `pytest tests/perception/test_schema.py` |
| A2 | 标签映射表覆盖所有用到的模型和数据集（SenseVoice 7 类、emotion2vec 9 类、AffectNet 8 类、M3ED 7 类、SMP 6 类），每个映射有单元测试 | 同上 |
| A3 | 任一模态缺失（没脸、没说话）时融合层仍输出结果，且 `confidence` 降低 | 构造缺失输入的单元测试 |
| A4 | 一条命令启动实时管线：摄像头 + 麦克风 → 屏幕上实时显示三路结果和融合结果 | 手动验收 + 录屏 |
| A5 | 一条命令跑完全部离线评测，输出 B、C 组所有数字到一个 Markdown 表 | `python -m perception.eval --all` |

## B. 复现精度（证明"会用主流方法"）

| 编号 | 模态 | 设置 | 锚点（作者报告） | 通过阈值 |
|---|---|---|---|---|
| B1 | FER | EmotiEffNet-B0 (`enet_b0_8_va_mtl`) 在 AffectNet val，8 类准确率 | 61.93% | 差距 ≤ 1.5 个点 |
| B2 | FER | 同上，V/A 的 CCC | V 0.594 / A 0.549 | 每项差距 ≤ 0.03 |
| B3 | FER（动态） | MAE-DFER 在 DFEW fold 1，UAR / WAR | 论文表格 fold 1 或 5 折平均 | UAR 差距 ≤ 2 个点 |
| B4 | SER | emotion2vec+ large 特征 + 线性头，按 EmoBox 划分在 RAVDESS、CREMA-D 上 | EmoBox 论文表格 | UA 差距 ≤ 2 个点 |
| B5 | SER | SenseVoiceSmall zero-shot 在 CASIA 或 RAVDESS 上（用仓库自带的 SER 评测脚本） | SenseVoice README 表格 | UA 差距 ≤ 2 个点 |
| B6 | TER | Chinese RoBERTa-base 在 M3ED 文本上微调（单句，不用上下文） | M3ED 论文 text-only 基线 | 不低于论文基线 |
| B7 | TER | LLM ERC（Qwen 7B QLoRA，带上下文） | 和 B6 比 | macro-F1 比 B6 至少高 3 个点；否则写清楚原因 |

如果数据集申请没批下来，B1–B3 用 RAF-DB 或 FERV39k 替代，锚点换成对应论文数字，并在报告里注明。

## C. 中文对话场景精度（证明"能用到实际场景"）

### C1 共用评测集：M3ED 测试集（7 类）

| 方法 | 通过阈值 |
|---|---|
| 每个单模态最佳方法 | UAR 明显高于随机（≥ 25%），并列出各类召回率 |
| Late fusion（置信度加权） | macro-F1 **≥ 最佳单模态 + 3 个点** |
| LLM 融合 或 Omni 端到端 | 只要求报告数字，和 late fusion 对比，写出结论 |
| TER 用 SenseVoice 转写 vs 用 M3ED 标注文本 | 报告两者差距（ASR 误差的代价），差距 > 5 个点要分析原因 |

### C2 自采数据集（用机器人头的摄像头和麦克风录）

**采集规格**：≥ 3 个人；每人每类情绪 ≥ 10 句（7 类 × 10 = 70 句/人），分"刻意表演"和"自然对话"两部分；同时录"舵机静止"和"舵机运动"两种条件的子集。标签由说话人自己给（自报）加 1 个旁观者标注，**两人不一致的样本单独存，不进主指标**。总量约 250–300 句，一个周末可以录完。

| 编号 | 指标 | 第一版阈值 |
|---|---|---|
| C2.1 | 表演部分，融合 7 类 macro-F1 | ≥ 0.55 |
| C2.2 | 自然对话部分，融合 7 类 macro-F1 | ≥ 0.35 |
| C2.3 | 融合 vs 最佳单模态 | 两部分都不比最佳单模态差；至少一部分高 ≥ 3 个点 |
| C2.4 | 跨人：留一人测试（训练只用其他人做校准） | 和人内结果的差距要报告；不设通过线 |

### C3 语气和字面矛盾集（这是机器人对话最需要的能力）

自采 **≥ 30 句**"字面积极、语气消极"或反过来的句子（例："太好了，又加班"用无奈 / 生气的语气）。标签以语气和表情为准。

| 指标 | 阈值 |
|---|---|
| 纯文本 TER 在这个集合上的准确率 | 只报告（预计很低，作为对照） |
| 融合结果准确率 | **≥ 50%**，并且 ≥ 纯文本 + 30 个点 |

## D. 鲁棒性

| 编号 | 条件 | 阈值 |
|---|---|---|
| D1 | FER 在暗光（关主灯、只开补光）和侧脸 ±30° 下 | macro-F1 下降 ≤ 10 个点 |
| D2 | SER 在舵机运动 vs 静止 | UA 下降 ≤ 5 个点 |
| D3 | 机器人 TTS 自言自语 5 分钟，没有人说话 | SER / TER 误触发 **0 次** |
| D4 | 画面中两个人 | 只输出主说话人（离镜头最近或正在说话的人）的结果，人工检查 20 次至少 18 次正确 |

## E. 实时性能（MacBook Air M4 16GB 实测）

| 编号 | 指标 | 阈值 |
|---|---|---|
| E1 | FER 帧率（检测 + 识别） | ≥ 15 fps 持续 |
| E2 | 一句话说完 → 融合结果出来（不含 LLM 融合） | p95 ≤ 500 ms |
| E3 | 含 Qwen3-4B 融合 | p95 ≤ 1.5 s |
| E4 | 感知管线总内存 | ≤ 7 GB |
| E5 | 持续运行 30 分钟 | 不崩溃；E1 帧率下降 ≤ 30%（无风扇降频） |

| 编号 | 标准 |
