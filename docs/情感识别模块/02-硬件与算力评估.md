# 02 硬件与算力评估

> 本机配置（`system_profiler` 读出）：**MacBook Air，Apple M4，10 核 CPU（4P + 6E），8 核 GPU，16 GB 统一内存，macOS 15.6.1**。
> 磁盘：内置盘只剩约 **19 GB**；`/Volumes/Robotics` 剩约 **567 GB**。
> 下面的延迟和训练时长是根据模型规模推算的，**没有在这台机器上实测**，验收时要以实测为准（见 03 的 E 组指标）。

---

## 1. 两个必须先处理的约束

1. **磁盘**：所有模型权重、数据集、HF / ModelScope 缓存都放 `/Volumes/Robotics`。运行前设置：
   ```bash
   export HF_HOME=/Volumes/Robotics/cache/huggingface
   export MODELSCOPE_CACHE=/Volumes/Robotics/cache/modelscope
   export TORCH_HOME=/Volumes/Robotics/cache/torch
   ```
   `~/.cache/huggingface` 里已经有东西，确认后再迁移，不要往内置盘继续写。
2. **散热**：MacBook Air 没有风扇，持续满载几分钟后会降频。实时 demo 要做 **30 分钟持续运行测试**，看 FER 帧率有没有掉；长时间特征提取放到晚上跑或者上云。

## 2. 本地可行性（逐项）

### 2.1 推理（全部能在本地跑）

| 组件 | 模型规模 | 内存估计 | 预计速度 | 结论 |
|---|---|---|---|---|
| 人脸检测（MediaPipe / YuNet） | < 5M | < 200 MB | 实时，> 30 fps | ✅ |
| FER：EmotiEffNet-B0（ONNX） | ~4M | < 300 MB | 单张脸几毫秒，> 30 fps | ✅ 主力 |
| FER：OpenFace 3.0（AU） | 小 | < 1 GB | 实时级 | ✅ 可选，只做研究 |
| FER：MAE-DFER / DFER-CLIP（ViT-B，视频片段） | ~90–150M | 1–2 GB | 每个 16 帧片段几百毫秒（MPS） | ✅ 能跑，但不做实时，只在句尾跑一次 |
| SER + ASR：SenseVoiceSmall | 234M | ~1 GB | 非自回归，一句话预计 < 200 ms | ✅ 主力 |
| SER：emotion2vec+ large | ~300M | ~1.5 GB | 一句话预计 < 300 ms | ✅ |
| SER：audeering w2v2 dim（V/A） | ~165M（12 层） | ~1 GB | 一句话 < 300 ms | ✅ 仅研究用（NC 许可） |
| TER：Chinese RoBERTa-base 分类头 | ~100M | < 1 GB | < 20 ms | ✅ 主力 |
| TER / 融合：LLM 4-bit（MLX） | Qwen3-4B ≈ 2.5 GB；8B ≈ 5 GB | 见右 | 4B 约 30–60 token/s（估） | ✅ 4B 可以和其他模型同时常驻；8B 能跑但会挤压内存 |
| 全模态：Qwen2.5-Omni-7B（BF16） | 7B + 编码器 | > 16 GB | — | ❌ 本地放不下，**上云** |
| Qwen2.5-Omni-3B（4-bit） | 3B | ~3–4 GB | 慢 | ⚠️ 可试，只做离线小样本对照 |

**实时管线的内存预算**：检测 + EmotiEffNet + SenseVoice + emotion2vec+ + RoBERTa + Qwen3-4B（4-bit）合计约 **6–7 GB**，16 GB 机器上可以留出给系统和 UI。这就是验收里"感知总内存 ≤ 7 GB"的来源。

### 2.2 训练 / 微调

| 任务 | 数据量 | 本地可行性 | 说明 |
|---|---|---|---|
| SER：emotion2vec+ 特征 + 线性 / MLP 头 | EmoBox 单个数据集几千条 | ✅ | 先离线抽特征（一次，几十分钟），头部训练在 CPU 上几分钟 |
| SER：V/A 回归头（在 emotion2vec+ 特征上） | MSP-Podcast 需申请；先用 CH-SIMS / M3ED 的标签近似 | ✅ | 同上 |
| FER：EmotiEffNet-B0 在 RAF-DB 上微调 | ~15k 张 | ✅（MPS） | 预计每 epoch 几分钟到十几分钟 |
| FER：自采数据的个性化校准（只训最后一层） | 几百张 | ✅ | 分钟级 |
| TER：Chinese RoBERTa-base 在 M3ED 文本上微调 | ~24k 句 | ✅（MPS） | 预计每 epoch 十几到几十分钟；batch 小一点 |
| TER：Qwen 7B LoRA（InstructERC 路线） | M3ED / MELD | ❌ | 16 GB 统一内存做 7B LoRA 太勉强，**上云** |
| 动态 FER：MAE-DFER / DFER-CLIP 在 DFEW 5 折上微调 | 16k 视频 × 5 折 | ❌ | 视频解码 + ViT，本地太慢，**上云** |
| 全模态 / MLLM 对照：Qwen-Omni、Emotion-LLaMA 在 M3ED 测试集上推理 | 几千条 | ❌ | 权重放不下，**上云** |

**本地完成的部分**：所有实时推理、所有"抽特征 + 训小头"、静态 FER 微调、RoBERTa 微调、自采数据的采集和评测。这些覆盖了验收标准的大部分。

## 3. 云 GPU 方案

### 3.1 配置

| 用途 | 推荐配置 | 原因 |
|---|---|---|
| 动态 FER 微调（MAE-DFER / DFER-CLIP） | **1 × RTX 4090 24GB**，≥ 16 核 CPU，≥ 64 GB 内存，**≥ 200 GB 数据盘** | ViT-B 视频模型 24 GB 显存够用；瓶颈常在视频解码，CPU 核数要够；先把 DFEW 抽帧成图片再训 |
| LLM ERC LoRA（Qwen2.5/3-7B） | **1 × RTX 4090 24GB（QLoRA）** 或 1 × A100/A800 80GB（BF16 LoRA） | 7B QLoRA 在 24 GB 能跑；80 GB 更快、能开更大 batch 和更长上下文 |
| Qwen2.5-Omni-7B / Emotion-LLaMA 批量推理 | **1 × A100/A800 80GB** 或 L40S 48GB | 音视频 token 多，显存占用远大于纯文本 7B |

一次只租一张卡，不需要多卡。和 ARM101 的训练用同一个云平台，镜像和数据盘可以复用。

### 3.2 时长估计

| 任务 | 估计卡时 |
|---|---|
| DFEW 抽帧预处理 | 3–5（CPU 为主，可以用便宜实例） |
| MAE-DFER 微调：DFEW 1 折完整 + 其余 4 折缩短 | 20–30 |
| DFER-CLIP 微调 1 折 | 6–10 |
| Qwen 7B QLoRA ERC：M3ED，3 epoch，加 2 组消融 | 8–12 |
| Qwen-Omni / Emotion-LLaMA 在 M3ED 测试集 + 自采集上推理 | 4–6 |
| 调试和返工余量 | 10 |
| **合计** | **约 50–70 卡时** |

### 3.3 预算

- 国内平台（AutoDL 等）RTX 4090 按小时计费，常见价位在每小时几块人民币，A100/A800 80GB 更贵（大约是 4090 的 2–3 倍）。**价格随供需变动，下单前以平台实时报价为准**，我没能拿到 AutoDL 当前的官方报价。
- 海外参考（第三方汇总，2026 年）：RTX 4090 约 $0.3–0.8/小时，A100 80GB 约 $0.9–2.0/小时（[promptquorum 汇总](https://www.promptquorum.com/zh/prompt-bites/cloud-gpu-cost-per-hour) · [synpixcloud 对比](https://www.synpixcloud.com/zh/blog/cloud-gpu-pricing-comparison-2026)）。
- 按 60 卡时、其中 50 小时 4090 + 10 小时 A100 粗算，**总花费大约在几百元人民币量级**。存储费另算：数据盘 200 GB 放一个月也是几十元量级。

### 3.4 省钱做法

1. 预处理（抽帧、抽 SSL 特征）尽量在本地做完，上传特征而不是原始视频。
2. DFEW 先只跑 1 折完整训练，确认能复现论文数字后再决定要不要跑满 5 折。
3. Omni / MLLM 只在测试集和自采集上推理，不做微调。
4. 用完立刻关机；数据盘保留，实例释放。

## 4. 机器人头本身带来的硬件问题（Mac 之外）

| 问题 | 影响 | 处理 |
|---|---|---|
| 21 个舵机 + 50 mm 风扇就在麦克风旁边 | SER 输入噪声，尤其舵机运动时 | 麦克风别装在头里，用桌面麦克风或领夹麦；舵机运动时打标记，评测"舵机开 / 关"两种条件（验收 D2） |
| 机器人自己用 TTS 说话 | SER / ASR 会识别到自己的声音 | TTS 播放期间关闭 SER（半双工），或者加回声消除；验收 D3 |
| 摄像头位置 | 仰视角、侧脸会降低 FER 精度 | 摄像头放在头部正下方或眼睛高度，自采数据时固定机位；`复现计划.md` 里 L2 的第二个摄像头是拍机器人自己的，和这个摄像头分开 |
| 光照 | 室内暗光下人脸检测掉帧 | 加一个补光灯，自采时记录光照条件 |
