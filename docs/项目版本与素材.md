## 大文件存放

本机 T9 挂载为 `/Volumes/Robotics`，项目位于 `/Volumes/Robotics/projects/head`。

| 位置 | 保存内容 |
|---|---|
| `ppt/` | 原始 MOV、剪辑、图片原件与演示稿，约 2.5 GiB |
| `models/` | 模型权重，约 590 MiB |
| `emo_bench/data/` | 评测数据，约 541 MiB |
| `upstream/` | 原作者 CAD、参考模型和下载包，约 417 MiB |
| `outputs/` | 渲染、缓存、日志等，约 204 MiB |
| `print_package/` | STL、3MF 和补打包，约 134 MiB |
| `机器人头_打印包.zip` | 完整打印压缩包，约 58 MiB |
| `.venv/` | 本机运行环境，约 364 MiB |

这些路径均保留原位。note 只新增文档、必要的小图和 HTML；评测报告中的视频链接回 T9，需要挂载磁盘。此清单不承诺文件已上传到 GitHub Release。

整理前的 README、四份被更新的 note 文件、原始 Git 差异和校验清单备份于同盘 `projects/head-整理备份-2026-11-09/`。它是回退副本，不是跨磁盘备份。
