# EmotionBot：会读"语气"的机器人头

## 一句话

让机器人头不只听得懂你说什么，还听得懂你怎么说——当字面积极、语气低落时，它会露出担心而不是开心。

## 200 字简介（提交表单用）

EmotionBot 是一个能感知情绪并做出回应的机器人头。它用 T5AI-Board 采音、USB 摄像头看人，在本地笔记本上同时运行语音识别、语音情感、人脸情绪和文本情感四路模型，融合后判断说话人的真实情绪。核心创新是"字面/语气矛盾检测"：当你说"太好了，又要加班"时，字面是开心的，声音却是疲惫的，系统会识别出这种反差，把表情切换成"担心"，并用一句符合语气的话回应。所有判断实时显示在网页仪表盘上。整条链路本地推理，8GB 显存即可运行，断网也能降级工作。

## 完整介绍

### 要解决的问题

现有语音助手能听懂"说了什么"，却听不懂"怎么说"。同一句"我没事"，可以是平静、可能是失落，也可能是强撑。情绪信息大量藏在语气、表情和字面之间的矛盾里。如果机器人只按字面回应，就会在最需要共情的时候显得冷漠。

### 我们做了什么

给 Will Cogley 的开源机器人头（22 维舵机动作空间，3 块 Pico 驱动）接上一套实时情感闭环：

1. **听**：T5AI-Board 采集 16kHz 音频传到笔记本，VAD 自动切句；SenseVoice 一次推理同时得到文字和语音情感标签，emotion2vec 输出 7 类情绪概率。
2. **看**：USB 摄像头实时做人脸检测与表情识别，补充"嘴上说没事、脸上写着难过"的线索。
3. **读**：对识别出的文字做字面情感判断——刻意只看字面，不做反讽猜测，把"言外之意"留给下一步。
4. **融合与矛盾检测**：按各模态置信度加权融合概率；当文本效价与语音效价符号相反、两边都足够确信时，判定为矛盾，并让结果跟随语气而不是字面。
5. **表达**：规则策略把情绪映射成表情强度和时长（开心 0.8/2.5 秒、愤怒 0.55 收敛不吓人……），驱动机器头做表情，同时用 TTS 说一句回应；说话期间做回声门控，避免机器人听见自己。

### 技术亮点

- **矛盾检测**是 demo 的核心：把"口是心非"从一个识别难题，变成一个能被看见、被验证的决策结果。
- **置信度门控**：模型不确定时不乱反应，保持中性，避免"瞎共情"。
- **全本地推理**：四路模型常驻显存约 2.5GB，RTX 4060 Laptop 8GB 即可跑完整个感知链路，不依赖云端。
- **全链路可视**：网页仪表盘实时显示四路概率、融合结果、矛盾横幅、22 维表情驱动和端到端延迟，评委能直接看到"它为什么这么判断"。
- **处处有兜底**：摄像头缺失走纯音频；T5 没调通走笔记本麦克风；在线 TTS 断网走本地 TTS；机器头没装完走仪表盘 2D 脸。任何一环出问题，demo 都还能演。

### 现场演示（约 3 分钟）

1. 说一句"今天特别开心"→ 机器头开心，语音回应。
2. 说一句"烦死了，真的受不了"→ 表情收敛的生气，语气缓和地回应。
3. 说一句"太好了，又要加班"→ 字面开心、语气疲惫，仪表盘亮起矛盾提示，机器头露出**担心**的表情，回应顺着语气走。
4. 遮住摄像头再说一句 → 仪表盘显示模态缺失、置信度下降，系统仍能给出判断。

### 应用场景

陪伴与养老陪护、客服质检（识别"嘴上满意、语气不满"）、心理健康初筛、教育与交互玩具。核心能力是同一套：不只听内容，还听得出情绪和反差。

### 团队分工

- 感知与中枢决策：情绪建模、多模态融合、矛盾检测、表情策略、实时管线与仪表盘
- 机械与装配：机器人头结构、舵机标定
- 板端与音频：T5AI-Board 采音与音频传输
