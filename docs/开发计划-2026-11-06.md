## 二、上午：真实麦克风链路（最高优先级）

**为什么先做**：这是唯一还没验证的核心路径，风险最高，也最可能暴露 VAD 和延迟问题。

| 顺序 | 任务 | 做法 | 验收标准 |
|---|---|---|---|
| 1 | 麦克风接入与设备选择 | `--mic-device` 指定实际麦克风，避开虚拟设备 | selfcheck 能录到非静音波形 |
| 2 | 实时链路最小闭环 | `python -m app.run --source mic --sim --no-face` | 说一句话，控制台 1 秒内出 `[event]` |
| 3 | VAD 阈值标定 | 现场噪声下调整静音切句时长、最短句长 | 正常说话不被切断，静音不误触发 |
| 4 | 延迟测量 | 连续说 20 句，记录 `latency_ms` | 融合结果 p95 ≤ 500ms（不含 LLM） |
| 5 | 回声门控 | 开着 TTS 自说自话 5 分钟 | 机器人自己的声音 0 次触发新事件 |
| 6 | 端到端观感 | 看仪表盘 + 听回应 | 一句话结束到表情变化 ≤ 0.8s，TTS 首字 ≤ 1.5s |

**如果麦克风上午到不了**：用手机录 5 句真实语音（16kHz wav），走
`python -m app.run --source file --wav xxx.wav --realtime --sim --no-face`，
除输入方式外链路完全一致，不阻塞后面任务。

## 三、上午后半段：矛盾检测实测（demo 核心卖点）

准备 10–20 句"字面积极、语气消极"的句子，真人录音，逐条回放：

- 「太好了，又要加班」
- 「我没事，你别管我」
- 「挺好的，真的挺好的」
- 「谢谢你啊」（阴阳怪气）
- 对照组：真开心、真生气、真难过各 3 句

记录表格：句子 / 文本标签 / 语音标签 / 是否判为矛盾 / 最终表情 / 是否符合预期。

**验收**：矛盾句识别率 ≥ 50%，且比纯文本判断高 ≥ 30 个百分点；对照句不被误判为矛盾。
**不达标时**：优先调矛盾判定的置信度阈值（当前两侧 >0.55），再调融合权重，不动模型。

## 四、下午：摄像头 FER 与多模态融合

| 顺序 | 任务 | 验收标准 |
|---|---|---|
| 1 | 摄像头 FER 单独验证 | 正脸 3 秒内出 7 类概率；遮挡/侧脸返回 None 不崩 |
| 2 | 三模态同时跑 | 仪表盘三个模态条同时有值，显存稳定不涨 |
| 3 | 模态缺失测试 | 遮住摄像头，融合置信度下降但结果不跳变 |
| 4 | 人脸 + 语音矛盾（加分项） | 笑着说难过的话，看是否进入 concerned |

**注意**：FER 帧率默认 8fps，显存和 CPU 都吃得少；如果和 ASR 抢 GPU 导致延迟上升，降到 5fps。

## 五、下午后半段：演示机（Linux 4060）环境验证

**为什么今天做**：现场才发现 Linux 环境问题的代价最大，必须提前一天暴露。

1. 把 `D:\emo_models` 整个目录拷到演示机（U 盘或 rsync）
2. 在演示机上：
   ```bash
   bash scripts/setup_env.sh --with-models     # 模型已有可去掉该参数
   source .venv/bin/activate
   python scripts/smoke_models.py
   ```
3. 检查项：CUDA 可用、两路模型加载、显存、麦克风/扬声器设备、`espeak-ng` 是否存在
4. 跑一次 `--stub --sim`，确认仪表盘在 Linux 浏览器/本机都能打开

**验收**：演示机上 `smoke_models.py` 输出 `SMOKE OK`，延迟与开发机在同一量级。

## 八、风险与兜底

| 风险 | 触发条件 | 兜底 |
|---|---|---|
| 麦克风延迟到货 | 中午前无可用输入 | 手机录音 + `--source file`，链路照样验证 |
| 真人矛盾句识别率低 | < 50% | 调阈值/权重；再不行用"文本积极 + 语音消极"的强对比句做 demo |
| ASR/SER 延迟过高 | p95 > 500ms | 换 fp16、降低 FER 频率、SER 换 base 版 |
| Linux 环境装不上 | 依赖冲突/驱动问题 | 记住错误原文，回退到 Windows 笔记本演示（T5/摄像头都是 USB，可换） |
| T5 音频没调通 | 队友未完成 | 全程用笔记本麦克风，demo 不受影响 |
| 回声误触发 | TTS 自己触发新事件 | 加长门控尾音 300→600ms，或降低扬声器音量 |
