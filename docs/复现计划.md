## 1. 这个头是什么

| 部分 | 舵机 | 控制板 | 原版代码 |
|---|---|---|---|
| 眼睛 | 6 个：眼球左右 LR、上下 UD，四片眼皮 TL/BL/TR/BR | Eyes_Brow_Neck PCB + Pico | `eyes.py` |
| 眉毛 | 4 个：左外 LO、左内 LI、右内 RI、右外 RO | 同一种 PCB 再做一块 + Pico | `Brows.py` |
| 嘴 | 11 个：下颌 JL/JR（MG996R），上下唇 LUL/LUR/LLL/LLR，嘴角 CUL/CUR/CLL/CLR，舌头 TON；另有一路没用到的备用口 EXA | Mouth Board PCB + Pico | `Mouth.py` / `MouthMaster.py` |

一共 **21 个舵机（19 个 MG90S + 2 个 MG996R），3 块树莓派 Pico**，没有脖子。这和官方页面写的"21 actuators"一致，见 4.1。

电路板（从 EasyEDA 文件里读出来的）：
- **Mouth Board**：Pico 插座、6 组 2×3 舵机排针（共 12 路）、AMS1117-5.0 给 Pico 供电、1000µF 和 220µF 滤波电容、SS1045 二极管、两个 Qwiic（1mm 4P）接口。
- **Eyes_Brow_Neck**：Pico 排针、L78M05 稳压、SS34 二极管、**12V / 5V 供电选择**、两个 Qwiic 接口。眼睛和眉毛各用一块。
- 3 块板之间用 Qwiic 线相连，但并**不是 I²C**：嘴部 Pico 把 GP16/17 当成 2 个数字位，给眼部和眉部板各发 4 种状态。

打印文件：`BambuPrintfile.3mf` 有 8 个 plate，直接用 Bambu Studio 打开。

## 2. 原版直接拿来做情感学习的问题

1. **电脑只能发离散命令**。电脑只连嘴部 Pico，眼睛和眉毛只能收到 2 个 bit，也就是 4 种状态（睁、闭、随机动；上、下、"开心"、"生气"）。没法连续控制视线、眼皮和眉毛，也就没法做表情学习。
2. **缺 `servo.py`**。原版 `from servo import Servo` 依赖的库不在压缩包里。
3. **`Mouth.py` 跑不起来**：第 104 行的 `for` 循环体全被注释掉了，报 `IndentationError`。实际能用的是 `MouthMaster.py`。
4. `HeadControlUI.py` 把串口写死成 Windows 的 `COM16`。
5. 眼部的 `eyes.py` 里写了电位器缩放和眼皮限位修正的函数，但都没被调用（标题写着 CONDENSED BOARD VERSION，像是从带旋钮的版本删过来的）。

## 3. 我做的改造（已完成，16 个测试通过）

位置：``

```
upstream/Head_α2.0.33/   原版文件的拷贝（CAD、PCB、代码）
firmware/                新固件：三块 Pico 刷同一份 main.py，只有 config 不同
  main.py servo.py config_eyes.py config_brows.py config_mouth.py flash.sh
head/                    电脑端 Python 包
  actuators.py           22 维动作空间，u ∈ [0,1]，直接读固件 config
  client.py              自动找串口、按名字或向量下发
  expressions.py         7 种基本表情（按 FACS 的 AU 设计）+ 混合
  blendshape_map.py      MediaPipe 52 个 blendshape → 舵机（22 维向量，含没用到的 EXA）
  viz.py                 2D 卡通脸预览，没硬件也能调
scripts/demo_expressions.py  轮播表情（--viz 只画图）
scripts/mimic.py             摄像头表情模仿，--record 存 (blendshape, u) 数据
tests/                   在 CPython 里用假硬件跑固件逻辑
```

**关键改动：每块 Pico 各接一根 USB 到电脑**（用一个 USB hub），不再走 2-bit GPIO。这样硬件不用改，电脑可以连续控制全部 21 个舵机。

串口协议（115200 波特率，每行一条命令）：

| 命令 | 作用 |
|---|---|
| `?` | 返回这块板是 eyes / brows / mouth，以及它管的舵机名 |
| `S LR=90 UD=100` | 设置目标角度，超出 config 范围的会被截断 |
| `G` | 读取当前角度 |
| `V 300` | 设置最大转速（°/s），固件会做限速插值，表情过渡更自然 |
| `R` / `C` / `X` | 回到 rest / 全部 90°（装舵盘时用）/ 卸力 |

动作空间：每个舵机一个 u ∈ [0,1]。u=0 和 u=1 分别对应 config 里的角度 a 和 b，含义统一成"睁眼程度、眉毛抬起程度、张嘴程度、嘴角上扬程度……"。学习算法只需要面对一个 22 维的 [0,1] 向量。

角度范围是从原版的 poses 和 servo_limits 里取的。**每个舵机的方向和范围都要装好后对着实物再标定**，改 `firmware/config_*.py` 就行，电脑端会自动跟着变。

7 种表情的 2D 预览：`outputs/expressions.png`

### 4.3 电路板：在嘉立创下单，自己焊

从 EasyEDA 文件里核对出来的供电路径：

- **嘴部板**：XT60 输入 **5V** → SS1045 二极管 → 12 路舵机电源；同时经过 AMS1117 → 跳线 → Pico。
- **眼部 / 眉部板**：XH 2P 输入 VIN → SS34 二极管 → 6 路舵机电源；同时经过 L78M05 → Pico。舵机电源**直接接在 VIN 上**，所以虽然板上写着 12V Select，**也只能接 5V**，接 12V 会烧舵机。
- 三块板都接同一个 5V 电源。Pico 同时插着 USB 也没问题，Pico 内部的 VBUS 有二极管隔离。

#### 下单 PCB（嘉立创）

文件在 `pcb/`，有两个 `.epro` 工程，外加一份合并好的元件 BOM。

| 板子 | 尺寸 | 数量 | 规格 |
|---|---|---|---|
| Eyes_Brow_Neck（眼眉板） | 26.7 × 62.5 mm | 需要 2 块（眼睛、眉毛各 1 块） | 双层板 |
| Mouth Board（嘴部板） | 72 × 55 mm | 需要 1 块 | 双层板 |

两块都是 10×10 cm 以内的双层板，打样很便宜，嘉立创经常有免费打样券。每种起订 5 块，多出来的当备件。

步骤：
1. 安装**嘉立创 EDA 专业版**（客户端，或网页版 pro.lceda.cn），登录嘉立创账号。
2. 用"文件 → 打开 / 导入"打开 `.epro`，进入 PCB 页面，先跑一遍 DRC 设计检查。
3. 选顶部菜单的"下单 → PCB 下单"，会直接跳到嘉立创下单页并自动带上制板文件。也可以选"导出 → PCB 制板文件（Gerber）"，再到 jlc.com 手动上传。
4. 下单参数：
   - 层数 2，FR-4，板厚 1.6 mm，铜厚 1 oz，数量 5，不需要拼板。
   - 表面处理选有铅喷锡，手焊最好上锡；无铅也可以。阻焊颜色随意。
   - **不要选 SMT 贴片**，自己焊。
   - 原因：板上元件几乎都是嘉立创的"扩展库"器件，每种扩展器件要单独加换料费，贴片反而比自己焊贵很多。
5. 两个工程分开下单，各 5 块。

#### 买元件（立创商城）

用 `pcb/立创商城BOM_3块板合计.csv`，已经按"2 块眼眉板 + 1 块嘴部板"把数量合计好，也加了备件。在立创商城（szlcsc.com）搜立创编号加入购物车，或者用"BOM 配单"上传这个文件。

表里"必需 = 否"的可以不买：
- 原版两板互联用的 1 mm 接口，本方案用不到。
- 指示灯和它的电阻，只是电源指示。
- 眼眉板上的 L78M05 和它的钽电容，只在接 12V 时用。

几个和原版不同的地方：
- **眼眉板的 Pico 插座**：原版用的是 1x20 排针，Pico 要直接焊上去。我改成 1x20 **排母**，配带排针的 Pico H，坏了可以直接拔下来换。排母在淘宝买就行。嘴部板原版就是排母，不用改。
- **眼眉板的供电选择**：板上有两个不放元件的 0805 焊盘，C11 标着"12V Select"，C12 标着"5V Select"。
  - 不是电容，是选择输入电压的跳线。
  - 本方案接 5V，**C12 用焊锡短接（或焊一个 0805 0Ω 电阻），C11 空着**。
  - 不短接的话，板子不会给 Pico 供电。插着 USB 时还能用，拔掉 USB 就不工作了。
- **嘴部板的 BOARD POWER**：一个 2P 排针，插上跳线帽，板子才会给 Pico 供电。

Pico 同时接板子电源和 USB 是安全的。Pico 板载有一个 VBUS 到 VSYS 的二极管，板子的 5V 不会倒灌回电脑的 USB 口。

**焊接难度：可以自己焊。** 贴片元件大多是大封装：

| 难度 | 元件 |
|---|---|
| 简单 | 插件排针 / 排母、拨动开关、XT60、XH 接口；SMD 电解电容（6.3 mm 和 10 mm）；SOT-223 的 AMS1117；TO-252 的 L78M05；SMB / SMA 二极管；1206 电阻 |
| 中等 | 0805 电容 ×2、钽电容（**注意极性**）、0603 指示灯（可以不焊） |
| 不用焊 | 两个 1 mm 间距的 SH 4P 接口（CN1、CN2）：只用于原版两板互联，新方案每块 Pico 各接一根 USB，用不到 |

工具：尖头烙铁、0.6 到 0.8 mm 焊锡丝、助焊膏、镊子、万用表。焊完先**不插 Pico、不接舵机**，用万用表量 5V 和 GND 之间没有短路，再上电测舵机电源和 Pico 供电的电压。电解电容、钽电容和二极管都有极性，按丝印方向焊。Pico 建议用排母插接，坏了方便换。

### 4.4 刷固件和调试（按这个顺序，不要一次装完再上电）

```bash
source /Volumes/Robotics/env.sh && cd /Volumes/Robotics/projects/head
```

## 5. 情感学习路线

| 阶段 | 做什么 | 依赖 | 对应工作 |
|---|---|---|---|
| L0 | 手工表情 + 2D 预览 | 已完成 | — |
| L1 表情模仿 | 摄像头看人，MediaPipe 出 blendshape，手写映射驱动舵机 | `scripts/mimic.py`，需要装 `.[vision]` 并下载模型 | 报告 5.3 方案 B |
| L2 学习自我模型 | 让机器人随机动舵机（motor babbling），另一个摄像头拍**它自己的脸**跑 MediaPipe，得到 (u, blendshape) 数据对。训练逆模型 blendshape → u，替换手写映射 | 第二个摄像头对准机器人 | Columbia Eva / Emo（Science Robotics 2024）的核心做法 |
| L3 感知到表达的闭环 | SenseVoice / emotion2vec（语音）+ 人脸情绪识别 → LLM 决定回应的表情和强度 → 机器人头 | 报告第 2、3 节的模型 | 调研报告里提到的"闭环评估"空白 |
| L4 用人的反馈优化 | 人对表情打分或做两两比较，用偏好学习或 RL 优化表情；进阶版把 ErrP 当奖励 | L3 + 用户实验 | HAPI；报告课题 1 |
| L5 提前预测表情 | 根据人脸前几百毫秒的变化，预测对方马上要笑，提前同步笑 | L2 的逆模型 + 时序模型 | Emo 的"提前约 840ms 预测微笑" |

**建议的第一个小目标**：做完 L1 和 L2，对比"手写映射"和"学到的逆模型"在表情模仿上的误差。评价方式是用 MediaPipe 分别处理人脸和机器人脸，比较两边 blendshape 的距离。这一步数据自己能采，不依赖别人，结果也容易量化。
