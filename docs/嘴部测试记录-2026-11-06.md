## 操作者说明（重要）

执行测试的操作者不熟悉硬件编号，**没有独立核对“脚本里的舵机名字”与“实物上具体哪个舵机”的一一对应关系**。操作者确认：

- 所有被测舵机都认真观察过，**都能运动，没有卡死、没有持续嗡嗡响、没有明显别劲**。
- 但“哪个编号对应哪个物理位置”没有对上号。
- 因此舵机之间的协同角度（尤其 JL/JR、CUL/CLL、CUR/CLR 三对）可能还需要按实物姿态调整。

阅读本文时请注意：

- 下文的方向、成对、行程结论，只表示“被点名的通道能驱动某个舵机且运动顺畅”，**不代表编号与物理位置的对应已经确认**。
- 端点值不是最终标定值。改 `config_mouth.py` 前，先按 `docs/舵机接线与上电检查.html` 复核编号、方向和成对关系。
- 在编号复核前，不要直接跑完整表情轮播。

## 1. 固件协议（未接 5V）

详见 [`固件协议测试记录-2026-11-06.md`](固件协议测试记录-2026-11-06.md)。要点：

- `S <name>=<deg>` 只给点名的舵机通电，按 `V` 的速度插值；多个舵机并行运动，不是排队。
- `O <names>` 只给点名的舵机通电，并**瞬间**写到 90°；第一次上电会有明显跳动。
- `R`、`C` 会给全部舵机通电；量程未确认前不要发。
- 角度按 `config_mouth.py` 的 a/b 截断；速度最低 10°/s。
- 畸形输入（`V` 无参数、`S JL` 无 `=` 等）会让固件抛异常退出主循环；测试时未在实机触发。
- `S` 是边解析边生效，遇到非法名字时前面的舵机已经被改动。

## 2. 断电检查

按 `docs/舵机接线与上电检查.html` 的编号，逐个检查 11 个舵机：

- 插头方向、针脚、线序（S/+/-）、舵盘/连杆、手动活动有无卡死。
- 操作者报 **11/11 通过**。

板级项目（BOARD POWER 跳线、XT60 断开、U3 是否最左、SW1 位置、线缆余量）**没有逐项书面确认**，下次上电前补。

## 3. 上电小步与方向

方法：`O <name>` 上电到 90°，每次 5°，保持 3 秒，回 90°，最后 `X`；速度 30°/s。

### 单个舵机

| 名字 | 测试 | 观察（测试时点名） |
|---|---|---|
| JL | `JL=85` | 下巴张开；第一次上电有明显跳变，无嗡嗡响 |
| JR | `JR=95` | 下巴张开，与 JL 同向；无嗡嗡响 |
| LUL | `LUL=85` | 上唇抬起（5° 时幅度小） |
| LUR | `LUR=95` | 上唇抬起 |
| LLL | `LLL=95` | 下唇往下 |
| LLR | `LLR=85` | 下唇往下 |
| CUL | `CUL=85` | 嘴角上抬 |
| CUR | `CUR=95` | 嘴角上抬 |
| CLL | `CLL=95` | 嘴角往后/变宽 |
| CLR | `CLR=85` | 嘴角往后/变宽 |
| TON | `TON=100` | 舌头往下 |

以上为测试时的点名观察；编号对应待复核（见开头说明）。

### 成对

| 对 | 测试 | 观察 |
|---|---|---|
| JL / JR | `JL=85 JR=95` | 未发现对顶/别劲 |

| CUR / CLR | `CUR=95 CLR=85` | 未发现对顶/别劲 |

### 10° 对称确认

| 组 | 测试 | 观察 |
|---|---|---|
| 上唇 | `LUL=80 LUR=100` | 两侧都向上 |
| 下唇 | `LLL=100 LLR=80` | 两侧都向下 |

同样，以上只表示两侧都能动、未别劲；编号与物理位置的对应待复核。

## 5. 结论与限制

- 所有被测通道都能运动，未发现卡死、持续嗡嗡响或明显别劲。
- 已测的配置端点都在安全范围内，暂不需要改 `config_mouth.py`；当天没有改固件、配置或代码。
- 由于编号映射未复核，本文的方向/成对结论只作为“运动正常”的记录，**不是最终标定**；成对协同角度可能需要调整。
- 剩余测试：CLL/CLR 变宽 4 步；TON 往下 6 步、往上 7 步。
- 收尾：确认各 rest 在安全范围 → `scripts/servo_check.py --board mouth` 慢扫 → `.venv/bin/python -m pytest -q tests`。
