人脸 / 语音 / 文本情绪识别：前沿方法测评

2026-10-19 · 1×RTX 4090 + 闭源 API。四个数据集（三个英文音视频、一个中文文本），从手工特征、自监督模型、大模型到闭源全模态 API 逐一测试。本页所有对比都可以点进去看具体是哪几条样本对了、哪几条错了，以及每条样本到底长什么样。

一句话结论

  1. 表演数据上，本地专用模型比闭源大模型高 20–35 分。同一批样本里，RAVDESS 上语音 + 人脸融合 89.3，最好的闭源 66.1。
  2. 真实对话（MELD）上反过来，闭源全模态更好——但它强在"听懂台词"，不是"看懂表情"。所有模型只看画面都在 9–29 之间，接近随机。
  3. 文本是对话场景最可靠的一路：Qwen3-8B + LoRA + 上文在两个对话数据集上都是本地最好。
  4. 部署时最大的损失在语音转文字（ASR）：同一个文本模型换成 ASR 转写，macro-F1 掉 13–18 分。
  5. 多人画面里，人脸模型找错了人。"取画面最大的脸"经常不是正在说话的人，部署前必须加说话人检测。
读数前先看这一条：闭源模型只测了每个数据集 56 条（每类 8 条，类别均衡）。56 条的 UA 误差约 ±13 分（95% 置信区间），所以相差 10 分以内的两个方法，不能说谁更好。本地模型也在同一批 56 条上重算了分数，保证可比。

UA、WA、macro-F1 分别是什么？
  • WA（weighted accuracy）= 普通准确率 = 答对条数 ÷ 总条数。类别不均衡时会被多数类绑架。
  • UA（unweighted accuracy，也叫 UAR）= 先算每个类别各自认对了几成（召回率），再把这些比例平均。每个类别一样重要。随机乱猜 7 类的 UA 是 14.3，6 类是 16.7。在本页 56 条的子集里每类数量相等，所以 UA = WA。
  • macro-F1：每个类别的 F1（同时考虑"认出来了多少"和"判成这一类的有多少是真的"）再平均。比 UA 多惩罚一种错误：把一大堆别的类都判成同一类。
  • 粗略的感觉：UA 30 大约是"比瞎猜好，但每类 8 条只能认对 2–3 条"；UA 60 是"大部分能认对，容易混的类（害怕 / 惊讶、悲伤 / 中性）经常错"；UA 85+ 是"基本只在个别样本上出错"。

不平衡数据上的分数陷阱

上面的 56 条是"每类等量"抽的。真实的完整测试集非常不均衡（MELD 里 48% 是 neutral），这时同一个模型的 WA 和 UA 会差很多。下面是几个代表性方法在完整测试集上的混淆矩阵（按行归一化成百分比，括号里是该类的样本数）。

关键发现

在真实对话里，加画面经常更差

怎么读：横轴是 4 个全模态模型，纵轴是同一批 56 条 MELD 样本上的 UA；蓝 = 只给音频，橙 = 只给无声视频，绿 = 视频 + 音频，紫 = 再加台词文字。灰色虚线是随机水平。数字来自模型回答，不是训练曲线。

橙柱全部贴着随机线；4 个模型里 3 个"加了画面"（绿）不如"只听声音"（蓝）。原因可以在逐条样本里看到：MELD 的镜头经常对着听的人、或者多人同框。

ASR 比换分类器更重要

怎么读：横轴是 6 种文本方法，纵轴是 MELD 完整测试集（2,610 句）的 macro-F1。蓝柱用人工标注台词，橙柱用 SenseVoice 自动转写，红字是两者之差。

每种方法换成 ASR 都掉 13–18 分，而最好和最差的文本方法之间（蓝柱之间）也就差 20 分左右。部署时先换更好的中文 ASR，收益最大。

三代方法：表演数据上提升明显，到对话全部塌掉

怎么读：横轴是三个数据集，纵轴是完整测试集上的 UA。浅蓝 / 深蓝 = 语音第 1 / 2 代（eGeMAPS / WavLM），浅橙 / 深橙 = 人脸第 1 / 2 代（HOG / EmotiEffNet），绿 = 语音 + 人脸融合。

表演数据上第 2 代比第 1 代高 10–27 分，融合再高 5–7 分；MELD 上所有方法都落到 15–36。
